## 1. Google：Gemini Decision 与 Decisions API 上线
**主线标签**：AI Agent（基础设施）/ 其他
- 发布：Gemini API 更新日志 2026-11-11 条目（厂商自报，已读官方模型页）。`gemini-decision-1` 是为 Decisions API 专门做的多模态模型：对文本、图像、音频、视频、PDF 提出带类型的问题，一次预填充（prefill）就返回校准过的概率，输出 token 为零。
- 能力（厂商自报）：一次请求最多 1,000 个独立问题，共享输入最多 262,144 token；题型有是非题（概率 0.01–0.99 加置信度）、单选（2–255 个选项）、评分（2–255 级量表，返回概率加权的期望分）。官方场景：请求路由、一次检查多条策略、按量表给候选打分、工具选择、实时媒体流上的低延迟分类。
- 价格（第三方转述，Simon Willison；官方定价页本次没读到）：每百万输入 $0.10，输出免费，与 OpenAI 的 GPT-6 Luna decision 模型同价，比 Jev 的 $0.042 贵。Simon 的小测试里，视频是非题给出 0.05、0.92 这类非 0/1 的概率。
- 为什么值得看：把「分类 / 路由 / 打分」从生成式调用里拆出来，做成便宜、可校准的专用接口，适合做 Agent 的路由和护栏。暂无技术报告。
- 来源：[Gemini API 更新日志](https://ai.google.dev/gemini-api/docs/changelog) · [Gemini Decision 模型页](https://ai.google.dev/gemini-api/docs/models/gemini-decision-1) · [Simon Willison（观点 / 第三方测试）](https://simonwillison.net/2026/Nov/11/gemini-decisions-api/)

## 2. Epoch AI：开放权重模型 GLM 5.3 自动攻破 Firefox 旧版本；Claude Fable 5.2 刷新 ECI
**主线标签**：AI Agent / 其他（评测）
- 来源性质：Epoch 是第三方独立评测机构，下面的数字是 Epoch 自己的实验结果（11-11 通讯，北京时间 11-12 01:18）；本次只读了通讯，没读完整报告，设置细节以 Epoch 原文为准。
- 安全实验（第三方独立，Epoch，离线沙箱）：GLM 5.3 在没有人工干预下，利用尚未送到用户手里的补丁反推攻击，对 6 个最新 Firefox 版本各做出能读取访问者本地文件的页面，每个版本成本约 $1,000；同样的做法在 Chrome 上没有复现。Epoch 的解读是「补丁空窗期」攻击会随开放权重模型变强而增多（防御侧启示：缩短补丁到用户的时间）。
- 能力指数（第三方独立，Epoch Capabilities Index）：Claude Fable 5.2（11-09 发布）得 174，超过此前最高的 GPT-6 Astra 的 169；Epoch 称高于推理模型的既有趋势。Epoch 同时把 ECI 的算法从频率学派改为贝叶斯，给出模型对比的胜率（如 Astra 胜 Claude Opus 5.5 的概率为 72%）；换算法后前沿模型分数平均只动约 1 分。
- 算力数据（第三方独立，Epoch）：全球新增 AI 算力约每 9 个月翻倍；到 2026 年 6 月，美国占累计 27.4 百万 H100 等效算力的 72%，中国 10%；Broadcom 的 TPU 出货在两个财季间翻倍，约 200 万 H100 等效。
- 为什么值得看：这是少有的独立数字，把「开放权重模型的网络攻击能力」和「最新前沿模型的位置」放在一起。ECI 是综合指数，不等于某个任务上的表现。
- 来源：[The Epoch Brief · 2026-11-11](https://epochai.substack.com/p/the-epoch-brief-november-11-2026)
