## 1. SemiAnalysis：实地探访「中国的 Stargate」——乌兰察布 Galaxy 数据中心园区

- **要点**（第三方 SemiAnalysis 实地报告，11-07 发布；以下只取免费部分，付费段落未读）：
  - 9 月探访的园区是远景（Envision）在乌兰察布的 Galaxy，规划 IT 容量最高约 **800MW**，体量约等于 OpenAI Abilene 核心园区；首期 **120MW** 一年内交付，SemiAnalysis 称成本约为美国的 **五分之一**。四期都是给两家互联网巨头定制建设。
  - 远景高度垂直整合：自建风电场和专用输电线，叶片工厂就在园区对面；自己设计 800V 低压电源模块、储能电池，并合作设计预制变电站。
  - 供电：在一个 5MW 机房里看到固态变压器（SST）把电网 10kV 交流直接变成 800V 直流给机柜，省掉中间的变压器、UPS 和整流环节。报告称中国过去十年新建数据中心约四分之一用直流，美国约 97% 仍用交流 UPS（SemiAnalysis 口径）。
  - 散热：液冷和风冷服务器共用一条水回路，不建集中冷水机组。周边察哈尔高新区约 3 万名施工人员在 22 个数据中心项目上作业（转引当地报道）；内蒙古已公布约 25GW 数据中心项目，下一篇会讲电、地、水等约束。
- **为什么值得看**：这是少见的一手现场材料，把「中国算力建得快、建得便宜」拆到了电力架构和散热设计层面，可以和美国 800V 直流路线图对照。不构成投资建议。主线：其他（算力基础设施）。
- **来源**：
  - [SemiAnalysis：We Visited China's Stargate in Inner Mongolia](https://newsletter.semianalysis.com/p/we-visited-chinas-stargate-in-inner)

## 2. （补录）蚂蚁 Ling 发布 Ling-3.2-flash：560B/25B 原生多模态 MoE，1M 上下文

- **要点**（厂商自报，Ant Ling 开发者平台更新日志，2026-11-05；11-06、11-07 简报未收录，今天 r/MachineLearning 有讨论，补一条）：
  - 原生多模态 MoE：总参数 560B、每步激活约 25B，上下文最长 1M，原生支持图像、文本、视频输入（不依赖外挂视觉模块，厂商说法）。
  - 主打四个方向：复杂视觉理解、多模态长程 Agent、3D 理解与交互、医疗多模态。
  - 可在网页对话里体验，API 同时兼容 OpenAI 和 Anthropic 协议；上线后前两周免费，之后价格官方页面暂未写明。
  - 开放程度：更新日志没有提到开源权重；HF `inclusionAI` 目前最新的公开权重仍是 Ling-3.1-flash-1019，没有 Ling-3.2 仓库。Reddit 帖子里列的 MathVision、AndroidWorld 等分数来自截图，本次没在官方文字页面核对到，先不引用。
  - 暂无技术报告。
- **为什么值得看**：国产开放平台里又多一个可以直接用 Claude Code / OpenAI SDK 接入的长上下文视频理解模型，适合试长视频分析和视觉 Agent。主线：多模态与具身智能（VLM/VLA）／AI Agent。
