## 1. Anthropic：Agent Memory 的组件——用「dreaming」整理、纠错和索引记忆

- **要点**（厂商自报，Engineering，Published Nov 6）：
  - 把 Agent Memory 定义为跨会话保留、可再读的经验知识（笔记 / 文件夹等），不包括改权重、单次上下文学习，以及 compaction 摘要替换旧轮次。
  - 类比海马体离线 replay：在会话间隙用 idle compute 做 **dreaming**——对照原始 transcript 纠错笔记、建 wiki 式表征、把重要条目提升到每会话预加载层（如 Claude Code auto memory 只注入 `MEMORY.md` 前 200 行或 25 KB）。
  - 评测例子（厂商自报）：CL-Bench 数据库任务上，更强 Claude 会把失败写成可验证规则并形成学习环；Pokémon 里 Sonnet 3.7 写了 413 个记忆文件只拿 1 枚徽章，Fable 5 只写 9 个文件拿 4 枚；对 Stainless 约 35 万文件 / 4.2 亿 token 语料，dreaming 从 2 轮到 128 轮后 25 题得分从约 13% 到 48%；wiki+搜索相对仅搜索约 54%→61%。
- **为什么值得看**：把「记忆」拆成写笔记、离线整理、表征维护和注入预算，是长程 Agent 产品落地的核心工程问题。主线：AI Agent。

  - [Anthropic：The components of agent memory](https://www.anthropic.com/research/components-of-agent-memory)

## 2. OpenAI：BioBasicsBench——100 个湿实验日常分析任务

- **要点**（厂商自报，与酶设计公司 Ligo 合作；页面日期 November 6；官方 X 同日推送）：
  - 覆盖蛋白方法、成像与流式、定量与 assay、核酸、分子克隆等；输入是凝胶 / blot、显微镜、测序、仪器导出、实验台照片与视频等**原始**证据，强调失败实验、模糊图像与冲突观察，而非论文精修图。
  - 任务由科学家用自有实验数据撰写并配专家 rubric，经内部未参与作者复审 + 外部湿实验 PhD 复审。
  - 结果（厂商自报，xhigh）：GPT-6 Astra 平均拿到约 **66.7%** 可用分（95% CI 约 60.3–73.1），GPT-5.6 Sol 约 **43.8%**；共测 7 个模型、37 个努力档、每任务 5 次、合计 18,500 次结果。文中也展示 Astra 仍会让假设压过对照、漏计菌落等失败模式。
- **为什么值得看**：把「科学 Agent」评测从论文图表拉回日常 wet-lab 判读与 biosafety 相关能力，数字可跟踪。主线：AI Agent／其他（科学应用）。

## 3. Google DeepMind：AI 智能体加速密码分析，暴露遗留 1024-bit RSA 新弱点

- **要点**（厂商自报；VP Science Pushmeet Kohli 长文 + 两篇技术论文；强调只针对已退役 1024-bit，现代 2048+ 仍安全）：
  - 在人类监督下，智能体用于压力测试加密「硬度」假设；与 Nadia Heninger（UCSD / Inria）、Emmanuel Thomé（Inria）等合作。
  - 数字签名方向：在攻击者控制签名块约一半及以上时，padding 几乎不再提供额外保护；在沙箱复现已解 1024-bit 基准密钥时，称相对此前学术实现约 **3.5×** 更少 CPU 时间、不到破译密钥本身算力的千分之一；短指纹场景称相对此前最优方法理论估计约 **1600×** 改进（1024-bit）。
  - 批量分解方向：称发现相对此前 batch 方法，额外每个 1024-bit 密钥的平均分解成本约降 **30×** 的新算法（渐近复杂度更好）。
  - 技术论文 PDF 已放出。技术报告 / 论文细节 13:30 技术报告雷达会归档、核验和精读，这里不展开。
- **为什么值得看**：把「Agent 做数学 / 密码分析」从口号变成可复核的硬度边界更新，对标准演进和防御优先级有直接含义。主线：其他（安全）／AI Agent。

  - [技术论文：Faster Affine Root…](https://storage.googleapis.com/deepmind-media/papers/Faster_Affine_Root_and_a_1024bit%20Computation.pdf)

## 4. Ai2：ToyBlocks——可控桌面机器人学习「培养皿」

- **要点**（Ai2 / HF 博客，November 6；开源）：
  - 提出 FoundationWorlds：受控仿真世界 + 自动任务/演示生成 + 行为指标。首个实例 ToyBlocks：单臂 + 桌面积木（可推、翻、堆，块面有字母/图案），在 Isaac Lab 里用 RL + 运动规划自动生成技能，TAMP 串技能产演示；单 GPU 并行可达约 **24×** 实时。
  - 初始数据：约 **85,336** 条长程演示（每条约 6–12 个技能演示）、约 **1,600** 小时执行、约 **1.44 亿** 帧；放出仿真资产、生成器、两个示例模型（Molmo 2 + ManiFlow）、训练/评测代码。[GitHub：allenai/ToyBlocks](https://github.com/allenai/ToyBlocks)
  - 结果摘录（厂商自报）：仅仿真训练的 ManiFlow 原子技能真实机成功率约 81.1%（仿真 80.0%）；Molmo 2+ManiFlow 拼字任务仿真 55.5%（111/200）、真实 50.0%（15/30）。用 Claude 等前沿模型经 MCP 做 search-and-spell 时约 63% 正确解决或正确判不可行，错误多来自形近字母与朝向。
- **为什么值得看**：给 VLA / 层级规划 / 世界模型一个可系统改数据、改模型、追失败原因的受控台架，而不是只能看窄演示视频。主线：多模态与具身智能（VLM/VLA）。
- **来源**：
  - [Ai2 / HF：ToyBlocks](https://huggingface.co/blog/allenai/toyblocks)
  - [allenai.org 同步稿](https://allenai.org/blog/toyblocks)

## 5. Anthropic 科学博客客座：教 AI 建科学模型（构建 / 约束 / 解释）

- **要点**（Science 客座文，Nov 6；作者 Jakob Macke、Daniel Gedon、Stefan Wahl，ELLIS / Tübingen；Anthropic AI for Science 受助方）：
  - 以 Hodgkin–Huxley 神经元模型为线，把建模拆成三步：建模型结构、用数据约束参数、解释模型对真实系统的含义；强调「拟合数据 ≠ 理解」。
  - 认为 AI 在 **simulation-based inference（SBI）** 约束参数上进展最大；用 LLM Agent 搜索模型空间可提出候选方程/程序，但应输出**兼容数据的模型分布**而非单一最优模型；解释仍最难交给 AI。
  - 展望连接组尺度脑模型等「太大写不出单一正确模型」的情形，主张问共享性质与可证伪预测。观点性客座文，非 Anthropic 自研基准成绩单。
- **为什么值得看**：把「AI for Science」从刷榜话术拆回科学方法本身，和昨天 Anthropic 科研会话分析、今天 BioBasicsBench 形成一条线。主线：其他（科学应用）／强化学习与RSI。
