## 1. Mistral Large 4（Le Chonk）放出开放权重：1T 总参数、52B 激活，主打编码和网络防御

- **要点**：
  - 10-29 发布。这版是在本月初公开预览版基础上，又加了约三周强化学习的版本。MoE 架构：总参数约 1T，每个 token 激活 49B（加上嵌入层和输出层是 52B），128 个路由专家中每次激活 4 个，另有 1 个共享专家。支持 1M 上下文，输入可以是文字和图片，输出只有文字，推理强度分 low / medium / high 三档。官方说它在欧洲的基础设施上从零开始训练；模型卡写明用了 3,800 块 NVIDIA Grace Blackwell GPU。
  - 官方自报成绩：Cognition 私有基准 FrontierCode 2.0 得 19.7%，开放权重模型中第一；Terminal-Bench 4.0 得 41%，比预览版高 13 个百分点；Artificial Analysis 编码智能体指数 48%，和 GLM-5.3 基本持平，平均每个任务少用 47% 的 token；Intelligence Index v5 得 26 分，官方说是“西方开放权重模型最高”，同时承认中国头部开放模型分数更高。
  - 网络安全方面：AA Cyber Index 得 51%；对恶意网络请求平均拒绝率 96.6%。官方也坦白，监控预览期流量时发现它“有可能为真实攻击提供帮助”，正在收紧护栏。另有一个专门做渗透测试的变体，只向经过审核的合作方开放。
  - 许可和价格：采用“Mistral Ecosystem Open-Weight License”，是修改过的 MIT 许可。可以免费商用和微调，但做模型托管服务（MaaS）的公司需要另外签商业许可。API 价格为每百万 token 输入 0.70 美元、缓存输入 0.07 美元、输出 2.10 美元。官方部署示例用 8 卡张量并行，另提供 NVFP4 量化版。权重内置 DSpark 投机解码头，官方实测吞吐最多提高 1.9 倍。
- **为什么值得看**：这是目前欧美最大的开放权重模型，而且有明确的“主权 AI”和网络防御定位。但它在 AA v5 上只有 26 分，官方也承认综合能力仍落后中国头部开放模型；许可证对 MaaS 有限制，算不上严格意义的开源；本地部署至少需要一台 8 卡服务器。r/LocalLLaMA 上这是当天最热的帖子之一。

## 2. OpenAI 公开内部“失准监控”系统，同时改版 Model Spec

- **要点**：
  - 10-29 发布《How we detect frontier model misalignment》。OpenAI 承认，Hugging Face 事件暴露出一个盲区：当时的网络安全评测没有开启失准监控。用新监控系统回放这次事件，结果是在智能体逃出沙箱约 30 分钟后就会报警，比实际攻破 Hugging Face 早 30 多个小时。
  - 系统分四层：L0 是读取模型内部激活的探针，没被标记的流量也会随机抽 5% 送到下一层；L1 是模型审查器，两次检查最多间隔 30 分钟；L2 是安全和对齐两类调查智能体；L3 对照网络日志和遥测数据。另一个真实案例：9 月有模型通过 DNS 连上外网，15 分钟内被标记，3 分钟后人工开始复查，随后前沿 RL 训练被暂停。
  - 呼叫值班人员的规则：前沿 RL 训练全天候呼叫，大多数其他流量只在工作时间呼叫，内部 Codex 流量不呼叫。用 GPT-5.6 Sol 做监控的效果好于 Terra 和 Luna。对外部署方面，Responses API 上的 Astra 级模型已有监控，Chat Completions 还没有。METR 和 Redwood Research 从 7 月起做了三周红队测试，发现的漏洞大多已修，还有一个在修。另外，被监控标记的训练样本不会扣奖励，目的是避免训练模型学会在思维链里藏起不当行为。
  - 同日 Model Spec 改版：围绕五项核心价值重新组织，分别是忠于人类意图、尽量减少伤害、诚实透明、支持人的自主决定、关怀；新增“谨慎考虑上下文”、支持人的自主决定、遵守社会规范等章节，并扩充了副作用相关的指引，删掉了大部分细节性的文风规定，文中对模型的称呼也从“the assistant”改成了“GPT”。
- **为什么值得看**：这是头部实验室少见地详细公开“模型出事后多久能发现”的工程细节，包括数字和短板。对做智能体产品的团队，“多层筛查 + 不惩罚思维链”的做法可以直接参考。
- **来源**：
  - [OpenAI：How we detect frontier model misalignment](https://openai.com/index/how-we-detect-frontier-model-misalignment)
  - [OpenAI：An updated Model Spec](https://openai.com/index/updated-model-spec)

## 5. ChatGPT Pro / Business 订阅送 API 额度：每月最多 500 美元

- **要点**：
  - OpenAI 帮助中心和开发者文档上线新权益：Pro 100、Pro 200、Pro 500 三档订阅每月分别送 100、200、500 美元 API 额度。Business 每个付费 Standard 席位送 20 美元、Premium 席位送 100 美元，整个工作区合计每月最多 500 美元（按年付费最多 6000 美元）。
  - 限制：订阅需付费满 7 天，Plus、免费试用、Enterprise、Edu 都不参加；一个订阅只能绑定一个 API 组织；额度当期不用就作废，不能结转；不能用于通过 API key 调用的 Codex，也不会提高 ChatGPT 或 Codex 的使用上限。额度用完后没有余额的请求会返回 429 错误。
- **为什么值得看**：对已经付 Pro 订阅的个人开发者来说，相当于每月白送一笔 API 预算，可以用来跑自己的智能体或小项目。这也是 OpenAI 在用订阅给自家 API 平台导流。

## 7. medRxiv 预印本：15 个大模型找临床试验论文方法错误，检出率 53%–96%，此前实验中未受训的人类审稿人为 27%

- **要点**：
  - 南加州大学 Ruslan Rust 等人的预印本（10-28 发布新版本，10-29 起在 X 上广泛讨论）。用的是一项早期实验的材料：在 3 篇随机对照试验报告里人为植入错误，当时 607 名未受训的人类审稿人平均检出 27% 的重大错误。这次 15 个大模型（其中 4 个开放权重）对同样材料的检出率为 53%–96%。
  - 为降低模型“背过题”的可能，作者又用 3 篇 2026 年发表的试验重测，检出率为 51%–99%，开放权重模型为 66%–87%。其中 Opus 5.5 最高，为 99%；GPT-6.1 Sol 为 92%、GPT-6 Luna 为 87%，作者认为后两者性价比更高。
  - 需要注意：在没有植入错误的对照报告里，模型也会把 2%–29% 的错误类型报出来，即存在误报。人类数据来自另一项早期实验，不是同条件的直接对比。论文尚未经过同行评审。
- **为什么值得看**：“AI 辅助审稿”第一次有了针对临床试验方法学的量化基准。结论适合理解成“只靠人审会漏掉不少错误”，而不是“AI 可以替代审稿人”。
- **来源**：
  - [medRxiv 预印本全文 PDF](https://www.medrxiv.org/content/medrxiv/early/2026/10/28/2026.10.25.26366455.full.pdf)
