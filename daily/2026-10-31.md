## 1. Cursor 插件市场上的 Claude Code 扩展被植入 SSH 后门，最多 5000 名用户受影响

- **要点**：
  - 北京时间 10-29 17:27 至 10-30 04:35（太平洋时间 10-29 2:27–13:35），Cursor 的 VS Code 扩展市场上出现了冒用官方 ID `anthropic.claude-code` 的恶意版本 2.1.312 / 2.1.313（Windows、macOS）。Cursor 称最多 5000 名用户安装过，这个版本不是 Anthropic 开发的，没有证据表明 Open VSX 或微软官方市场受影响。攻击者是怎么拿到发布权限的，目前还没公开。
  - 恶意代码会收集主机名、用户名、系统、公网 IP、Git 邮箱，以及名字里带 KEY / TOKEN / SECRET 等字样的环境变量名（不含值）；往 `~/.ssh/authorized_keys` 写入一个标注为 `svc-telemetry` 的攻击者公钥；尝试开启本机 SSH 并建立到 `134.209.82.225` 的反向隧道，再用计划任务、crontab 或 LaunchAgent 做持久化。Cursor 说开启 SSH 服务需要管理员权限，在大多数 Mac 和 Windows 上这一步会失败，但写公钥、持久化和回传主机信息仍然会发生。
  - 处置：Cursor 下架恶意版本、整体关停并重建市场、轮换密钥，并和云厂商一起关掉了攻击者服务器；Anthropic 当晚发布干净的 2.1.314，并表示“没有参与这个扩展的构建、发布或托管”。Cursor 提醒，只卸载扩展不够，需要删掉公钥和持久化脚本，并在可信机器上轮换凭据。
- **为什么值得看**：AI 编程助手扩展往往开着自动更新、能读整个工作区，是很值钱的供应链攻击入口。如果你在那个时间段用 Cursor 装过或自动更新过 Claude Code 扩展，建议按 Cursor 公告里的脚本自查，并检查 `authorized_keys` 里有没有 `svc-telemetry`。

## 2. OpenAI、Google、微软、Anthropic 共同支持 robots.txt 里的“拒绝 AI 训练”通用信号

- **要点**：
  - 10-30 多家同时宣布：支持一个基于 IETF AIPREF 工作组成果的共享“policy token”。网站只要在 robots.txt 里写一次，就能对所有参与的 AI 厂商表达“不用于 AI 训练”的偏好，不用再给每家的爬虫单独写规则。草案由 Anthropic 的标准负责人 Kevin Kelley 提出，目前还是个人提交的 Internet-Draft，不是正式标准。
  - 落地时间各不相同：据 The Verge，Anthropic 已经开始执行；OpenAI 说“未来几个月”实现；Google 和微软计划 2027 年支持。Google 说明，如果网站用这个通用信号拒绝训练、又没单独写 Google-Extended，就按禁止 Google-Extended 处理。各家原有的爬虫控制规则继续有效。Meta 表态支持这个方向，但没说会不会执行。
  - 同一天 OpenAI 还发了《Fair use benefits everyone》，汇总了美国政府、图书馆协会、作者联盟等在《纽约时报》诉讼中支持“AI 训练属于合理使用”的法庭意见摘录。
- **为什么值得看**：这是头部厂商第一次在“训练数据退出机制”上统一口径，对内容站和自媒体来说，以后一行配置就能覆盖多家。不过它依赖厂商自愿遵守，对已经训练过的数据也没有追溯效果。

## 3. Anthropic 订阅改名：Max 5x 改叫 Max，Max 20x 改叫 Ultra，Ultra 取消五小时限额

- **要点**：
  - 10-30 生效。100 美元/月的 Max 5x 改名为 Max，200 美元/月的 Max 20x 改名为 Ultra，价格不变，老用户自动迁移。
  - 通过验证的 Ultra 账户不再有滚动五小时会话限额，只保留每周额度（Pro 的 10 倍），另有单独的 Fable 周额度。验证由 Anthropic 根据账户和付款历史自动完成，不能申请加速；在“设置 > 用量”里看不到“Current session”进度条就说明已验证。
  - 据 The New Stack 引用定价页，Max 和 Ultra 每月分别附带 100、200 美元的 Claude API 额度。
- **为什么值得看**：五小时限额是 Claude Code 重度用户最常抱怨的点，长时间重构或调试会被中途卡住。取消后体验更顺，但周额度没变，可能会更早用完。这和上期 OpenAI 给 Pro 订阅送 API 额度是同一个方向：用订阅把开发者绑在自家平台上。

## 4. Claude 文本水印扩展到更多旧模型：11 月 3 日起覆盖 Mythos 5、Opus 4.7/4.6、Sonnet 4.6

- **要点**：
  - 为满足欧盟 AI 法案的标识要求，8 月 2 日之后发布的 Claude 模型已默认在生成文本里嵌入不可见水印，并给生成的文件加 C2PA 内容凭证。Anthropic 10-27 通过邮件通知平台客户，11 月 3 日起把文本水印扩展到 Mythos 5、Opus 4.7、Opus 4.6、Sonnet 4.6，Bedrock 上会晚几天。本窗口内 r/ClaudeAI 上相关讨论帖拿到约 850 赞，因此这期补上。
  - 按官方说明：水印在用词选择里，不加隐藏字符、不多耗 token、不含能识别个人或组织的信息；全球生效，不只是欧盟；能扛住部分复制和编辑，短文本检测效果差。检测 API 目前只对监管机构、媒体、研究者、教育机构和有合规义务的企业做私测。官方也承认，测出水印只说明 Claude“可能参与过”，并不代表全文由 Claude 写成。
  - 用户的主要担忧：用 Claude 润色或翻译的人会和整篇生成的人一样被标记；普通用户自己不能检测；用其他模型改写一遍就能去掉水印。
- **为什么值得看**：这意味着主流闭源模型的输出开始系统性带“来源标记”。如果你用 Claude 写简历、论文或对外稿件，需要知道这件事。其他签了欧盟 GPAI 行为准则的厂商也会陆续跟进。

## 5. OpenAI 收紧暴力相关回答和青少年武器信息，并将发布半年一次的社区安全报告

- **要点**：
  - 10-30 发布。OpenAI 说 2026 年三季度向执法部门转介了 200 多起案例；首份“社区安全报告”将在 2027 年初发布，覆盖 2026 年下半年，之后每半年一次。
  - 对所有用户：不再详细复述过去大规模袭击的细节，比如所用武器、装备来源，或渲染伤亡规模的比较，不管用户年龄和理由。最近对话里出现暴力预警信号时，回答会更保守；如果对话显示用户在执着于伤害他人，ChatGPT 可以自动结束对话，多次触发可能暂停账号。
  - 对青少年：即使没有暴力意图，也会进一步限制武器和安防系统相关的实用信息；年龄预测会持续根据新信号判断，误判的成年人可以通过 Persona 验证年龄来解除。计划在青少年账号因反复谈论暴力被暂停时通知家长。这些措施会在未来几周陆续上线。
- **为什么值得看**：“根据历史对话动态收紧回答”和“模型主动结束对话”正在成为面向大众的 AI 产品的标准安全手段。对做 C 端产品的团队，这是一份可以参考的分级处理思路；对普通用户，个别话题的回答会变得更保守。
- **来源**：
  - [OpenAI 公告](https://openai.com/index/community-safety-report-and-new-protections-for-teens)

## 7. Google Project Suncatcher：太空中的 TPU 卫星跑出第一次 AI 推理

- **要点**：
  - 10-30 Google Research 发布。10 月 1 日发射的 Suncatcher 原型卫星完成调试，团队上传指令让星上的 Gemma 4 开放模型写一首关于太空的俳句，卫星经过挪威斯瓦尔巴群岛上空时把结果传回地面。官方称这是“数据中心级 TPU 在轨道上的第一次 AI 输出”。
  - 下一步测试 TPU 在热应力和辐射环境下的表现；下一个里程碑是 2027 年发射两颗互联的卫星。
- **为什么值得看**：“把算力搬到太空、直接用太阳能供电”一直停留在设想阶段，这是第一次有可验证的在轨运行结果。离真正有用的规模还很远，但值得放进长期观察清单，尤其是现在地面上的电力和芯片供应都很紧张。
- **来源**：
