# ai-news

AI 论文原文（PDF）与中文深度解析归档。先按来源分，再按日期，再按论文一个文件夹。

## 目录结构

```
papers/
  huggingface/                       # 来源：Hugging Face 每日热门论文
    YYYY-MM-DD/
      README.md                      # 当日清单（标题、👍、机构、链接、PDF 与深度解析入口）
      <arxiv-id>-<short-english-title>/
        paper.pdf                    # 论文原文
        深度解析.md                  # 中文深度解析
  arxiv/                             # 来源：arXiv 每日精选「最值得先看」（补充归档）
    YYYY-MM-DD/
      README.md
      <arxiv-id>-<short-english-title>/
        paper.pdf
        深度解析.md
```
