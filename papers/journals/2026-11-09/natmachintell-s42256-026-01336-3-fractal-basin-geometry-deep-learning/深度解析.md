## 1. 一句话先懂它

同一份代码、同一个种子、哪怕只改了一个比特，训练出来的模型也可能落到完全不同的"终点"。这篇论文用物理里研究混沌的工具说明：这不是噪声没控干净，而是训练过程本身的几何结构决定的，把初始化精度再提高很多也几乎没用。

## 2. 值不值得读：五个 C 速览

**类型**是测量分析加理论机制。**上下文**接着两条线：一条是"训练不可复现"的经验研究（Summers & Dinneen 2021 的单比特扰动实验、Bhojanapalli 等人的预测 churn 研究），另一条是对称性诱导的不变子空间（Chen 等人的 stochastic collapse）和训练混沌（Herrmann 等人、作者自己 2025 年的 Nat. Commun. 工作）。**关键假设**是：网络里有对称性带来的不变子空间、子空间里有混沌吸引子、横向稳定性被大学习率削弱，三者同时成立；最小模型里作者逐条验证了，深度网络里只能看"迹象"。**贡献**：在 4 参数的最小网络里解析地走通"riddling"（筛孔状吸引域）的经典路径；在约 50 万个网络上测到接近零的不确定性指数；提出可以不看参数、只看预测的"函数空间不确定性指数"。**清晰度**不错，但大量稳健性结果放在没有随 PDF 附带的补充材料里。

建议读到第 5 节；做训练平台或模型评测的人值得翻原文 Fig.5 和 Extended Data Fig.7。

## 3. 它在解决什么麻烦

现在大家处理"训练结果不稳定"的做法基本是工程式的：固定随机种子、固定数据顺序、打开 cuDNN 确定性模式、跑多个种子取平均。背后的默认想法是——只要把外部随机性（初始化、批次顺序、数据增强、GPU 浮点误差）控制住，或者控制得足够精细，结果就会收敛到同一个答案。

但这个想法和实践经验对不上。你可能遇到过：线上模型重训一版，整体准确率几乎不变，可是有几个百分点的样本预测翻了（业内叫 churn，即"两个模型在同一批输入上给出不同答案的比例"），下游的规则、阈值、人工审核队列全跟着抖；或者做消融实验时，两组只差一个超参数的结果，差距还不如换个种子大。论文 p1 引用的已有证据更极端：去掉所有外部不确定性后，只改动一个参数的一个比特，产生的差异就和多种噪声源叠加差不多。

这篇论文想回答的是"为什么"。它的答案是：训练终点在参数空间里的"吸引域"（从哪些初始化出发会走到同一个终点，那一片区域就叫这个终点的吸引域）不是一块块干净的区域，而是彼此像筛子一样互相穿插，而且在任意小的尺度上都穿插。如果这是真的，那么"把随机性控制得更精细"这条路有天花板，工程上应该转向"承认差异存在并测量它、管理它"。

## 4. 他们怎么做的

**核心思路**：动力系统理论早就知道一种叫 riddled basin（筛孔状吸引域）的现象——只要满足"不变子空间里有混沌吸引子、吸引子里有横向不稳定的周期点、外面还有别的吸引子竞争"这几个条件，吸引域就会变成"胖分形"（fat fractal，有正体积、但处处有洞的分形）。深度网络恰好普遍具备这些成分：对称性（交换两个神经元或翻转符号不改变网络输出）制造不变子空间，大学习率制造混沌和不稳定。所以作者先在最小模型里把条件逐条验证，再去大网络里找同样的"指纹"。

**第一步：最小模型（p2–p5）。** 两层、两个隐藏神经元、tanh 激活，共 4 个参数，用确定性梯度下降拟合 8 个随机点（p3）。作者解析地找出 4 个由对称性诱导的不变平面，在学习率 2.5 时算出平面内吸引子的李雅普诺夫指数（衡量相邻轨迹分开得多快的指数，正数表示混沌）：纵向最大指数 0.1564 为正，横向两个指数 −0.0645、−0.2047 为负（p3），再用有限时间指数的正向波动（Fig.2b，p3）推断存在横向不稳定的周期点。条件齐了，就在 2,047×2,047 的初始化网格上画"终点地图"（Fig.3，p4），放大多次仍能看到穿插结构。

**第二步：不确定性指数（p4–p5）。** 定义 f(ε)：两个初始化相差不超过 ε 时，训练终点不同的概率。若 f(ε) 随 ε 按幂律下降，幂次 ϕ 就是不确定性指数。ϕ 越接近 0，提高精度越没用。最小模型测得 ϕp = 0.0126 ± 0.0002（Fig.3e，p4；n = 10⁴ 对），作者换算为"想让 f(ε) 减半，ε 要缩小近 24 个数量级"（p5）。

**第三步：深度网络（p5–p7, p9–p10）。** 代表性设置是 VGG-12（被压缩到 12,036 个参数、去掉偏置，p9），在 50% 标签噪声的 MNIST 上用 SGD（学习率 0.1、批大小 128、动量 0.9、权重衰减 5×10⁻⁴，p9）训练 30 个 epoch，固定数据顺序。终点用"最后一层哪些神经元归零"来识别（p10）。他们在参考初始化附近的 ε 小立方体里撒点，分别在 GPU 和 CPU（CPU 保证完全确定）上训练，拟合出 ϕp。

**第四步：函数空间指数（p5）。** 实际中大家关心的是预测而不是参数，所以作者把 f(ε) 换成 churn，拟合 churn 随 ε 的幂次 ϕf，并在附录用 32 种相似度指标重复（Extended Data Fig.3，p15）。

**如果让你复现**（函数空间诊断，不需要识别对称子空间）：

```
ref = init_model(seed=0)                    # 固定参考初始化
for eps in [1e-14, 1e-12, ..., 1e-6]:       # 跨多个数量级
    pairs = []
    for k in range(N_PAIRS):                # 论文用 250 对
        a = perturb(ref, U(-eps/2, eps/2))  # 每个参数加均匀小扰动
        b = perturb(ref, U(-eps/2, eps/2))
        A, B = train(a), train(b)           # 固定数据顺序，最好在 CPU 上确定性训练
        pairs.append(churn(A, B, test_set)) # 预测不一致的样本比例
    record(eps, mean(pairs))
phi_f = fit_power_law(eps_list, churn_list) # 接近 0 且 churn 明显大于 0 → 进入"riddling-like"区
```

阈值怎么定、拟合区间怎么选，正文只说在补充材料第 9 节做了稳健性检查，具体标准论文正文未说明。

## 5. 证据怎么看、别被什么忽悠

**Fig.5（p7）：深度网络的核心证据。** 想证明：在真实一点的网络里，提高初始化精度也换不来可复现性。怎么测：VGG-12 / 50% 噪声 MNIST，参考点为 Fig.4d 中心，ε 跨约十个数量级；f(ε) 每个 ε 用 10⁴ 次 bootstrap 重采样、每次 500 对；churn 用 250 对 CPU 训练的网络。结果：GPU 和 CPU 上都是 ϕp = 0.000 ± 0.002；churn 停在约 2.9%，ϕf = 0.00 ± 0.01（Fig.5 图注，p7）。说明：至少在这个设置下，差异不随 ε 变小而消失，而且 CPU 确定性训练排除了"GPU 浮点累积误差"的解释。

**Fig.1（p2）要读对。** 很多转述会引用 φ = 0.0050 ± 0.0006，但这是 Fig.1b **示意图**里的数（由最小模型 Fig.3c 放大区域生成，n = 10⁴ 对邻近初始化，p2、p10），不是深度网络实测；深度网络实测请用上面 Fig.5 的 ϕp = 0.000 ± 0.002。

**Extended Data Fig.6（p18）：BERT 微调。** 想证明：现象不限于小卷积网。在 IMDB 情感分类上微调预训练 BERT，接近最优学习率 5×10⁻⁵ 时 churn 平均 27%，ε 缩小 10 个数量级也不改善（ϕf = −0.001 ± 0.004）；换到明显偏小的学习率 10⁻⁷，churn 只有 0.1%。每个 ε 只有 50 对。

**Extended Data Fig.7（p19）：扰动大小无关。** 从翻转一个最低有效位、到加不同大小的随机扰动、再到换随机种子，100 次训练的测试准确率波动水平相近。配合 p6 的数字：只翻最低位时，终点不同的比例 f(ε) = 0.477。

**水分检查。** 第一，规模：代表网络只有 12,036 个参数（p9），作者坦言严格分析需要同时训练上万个网络，大模型算不起；"约 50 万个网络"（p5）是总数，大部分是这种小网络。第二，标签噪声：主实验用了 50% 错标签来加速收敛，作者在 Extended Data Fig.5（p17）给了无噪声对照，ϕp = −0.003 ± 0.007、churn 约 3.5%，方向一致。第三，"终点"的定义依赖阈值（神经元范数小于 10⁻²、训练 30 个 epoch，p10），作者也承认训练更久终点地图会变（p10）。第四，样本量：BERT、ResNet 部分只有 50 对（p16、p18）。第五，深度网络里看到的只是"与 riddling 一致的迹象"，没有像最小模型那样把三个条件逐一证明——作者自己的措辞也是"candidate organizing principle"（候选组织原理）。第六，另一种解释：ϕ≈0 也可能来自一般的混沌长时间放大，作者用"混沌只破坏轨迹级预测、不破坏终点级预测"区分（p6），但在深度网络里这一区分仍是间接的。

## 6. 可信度与核验限定

**主张对照。**
1. "最小模型满足 riddling 的全部理论条件"——证据在 Fig.2、Fig.3 和 Methods（p3–p4, p8–p9），有李雅普诺夫指数和扩散系数，证据较充分。
2. "深度网络参数空间指数接近 0"——Fig.5（p7），只有一个代表性参考点做了高精度测量，其余配置在补充材料，本次未读到，证据中等。
3. "现象在测试的架构、优化器、训练方案上都成立"——Extended Data Fig.4–6（p16–p18）加补充材料第 8 节，覆盖面有，但每个配置样本量较小。
4. "存在性能–可复现性权衡"——Extended Data Fig.8（p20）与补充材料；作者也给了反例（无标签噪声的配置没有这个权衡，Extended Data Fig.5 图注，p17）。

**核验限定（原样合入）。**
- φ = 0.0050 ± 0.0006 出自 Fig.1 示意图（p2，n=10⁴ 对邻近初始化）；深度网络实测 ϕp = 0.000 ± 0.002、ϕf = 0.00 ± 0.01（Fig.5 p7）
- 测试范围：VGGNet/ResNet/BERT，MNIST/CIFAR-10/IMDB，SGD/GD/AdamW（p5）
- 代码 Zenodo 10.5281/zenodo.23103493（MIT）；论文 CC BY 4.0

**打折提醒。** 对外别说"证明了深度学习不可复现"，应说"在所测的小规模配置里观察到与 riddling 一致的迹象，作者把它作为候选机制"。不要把 φ = 0.0050 当作深度网络结论引用。不要外推到大语言模型预训练，论文没有在那个规模上测。

## 7. 你可以怎么落地

**今天就能试**：给你现有的一个小训练任务（比如一个分类微调脚本）加一个"churn 监控"。做法是固定种子和数据顺序，把初始权重加一个极小扰动（例如每个参数加 ±1e-8 的均匀噪声）再训一次，在同一测试集上算两个模型预测不一致的比例，同时记录两者的准确率差。验收：如果准确率差不到 0.5 个百分点、但 churn 达到几个百分点，就说明你的流程里"同分不同答"是真实存在的，以后上线新模型时应把 churn 和准确率一起写进评估报告，而不是只看准确率。

**要有数据或机器再试**：复刻论文的函数空间诊断（第 4 节骨架）。前提是能并行训练几十到几百个小模型；建议先用论文 Zenodo 代码在 CPU 上跑 VGG-12/MNIST 的一个 ε 点，对上 churn 约 2.9% 的量级后，再换成你自己的模型和数据。分三步验证：先确认 CPU 上同初始化两次训练结果完全相同（确定性成立）；再扫 3–4 个数量级的 ε，看 churn 是否平；最后扫学习率，看 churn 是否在较小学习率处明显下降，判断你的配置在不在"riddling-like 区"。成本主要是训练次数，模型越大越贵。

**暂时别碰**：别为了"可复现"直接把学习率调到很小——论文显示可复现性提高往往伴随训练效果下降（p7）；也别据此认定"多跑几个种子取最好"就够了，那只是挑了一个终点，不代表下次能复现。论文提到的"打破对称性"类干预（p8）目前只有引用文献的支持，吸引域几何还没被刻画，暂不建议改模型结构。

## 8. 和你已有知识的挂钩

可以把它想成"超级版的蝴蝶效应"：普通混沌（比如天气预报）只是说细节预测不远，但大方向（会不会下雨）通常还算稳定；这里连"最后落到哪个盆地"都无法预测。另一个类比是分布式系统里的竞态条件：代码一样、输入一样，只是时序差一点，结果就不同——修法不是消除所有时序抖动，而是让系统对结果差异有容忍和监控。和 Sohl-Dickstein 2024 年"可训练性边界是分形"的工作最大的区别是：那里的分形只出现在边界上（"瘦"分形，提高精度就能避开），这里是整片区域都有洞（"胖"分形，提高精度也躲不掉）。

## 9. 存疑与代价

**局限。** 作者承认：严格分析需要同时训练上万个网络，无法在大模型上做（p9）；完整识别对称子空间对很多架构仍是开放问题（p5）。我读出来的：主结论依赖单一参考点的高分辨率测量；"终点"识别依赖阈值和训练长度；大量稳健性证据在补充材料，本次未读到。

**复现条件。** 代码与主数据在 Code Ocean 和 Zenodo 公开（p11）；数据集 MNIST、CIFAR-10、IMDB 均公开（p10）。

**成本。** 作者说实验在高性能计算集群上一周内可复现（p9）；对个人来说，主要成本是成百上千次重复训练。

**出处。** 期刊正式版、同行评审，两位作者同属悉尼大学物理学院，有公开评审人署名（p12）。

**三个论文没回答、但决定你要不要动手的问题。**
1. 在十亿参数级的预训练或大模型微调里，churn 平台有多高？是否也和 ε 无关？
2. 集成、蒸馏、权重平均这些常见手段，能否把函数空间的差异压到业务可接受的范围？
3. 如何在不牺牲训练效果的前提下离开"riddling-like 区"？
