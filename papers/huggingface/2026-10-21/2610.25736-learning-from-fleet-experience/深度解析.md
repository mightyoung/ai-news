# 从机器人集群经验中学习：一种群体学习范式

**Learning from Fleet Experience: A Collective Learning Paradigm for Robots**

## 一句话总结

让部署中的一大群机器人共享各自的执行经验，用"失败时去检索别的机器人成功做过的片段"来微调共同策略，初始化后不再需要额外人工纠错，96 台机器人把手机包装任务成功率从 79.2% 提到 98.3%。

## 研究问题与动机

机器人在部署中会产生大量执行经验，本可以用来提升策略可靠性。但主流的"人在环纠正"（如 HG-DAgger）需要遥操作员实时监控并在失败时接管，机队一大，这种人力需求就难以满足。作者希望机队自己的经验成为新的动作监督来源。

## 核心方法

1. **集体经验学习 CEL**：在专家监督初始化之后，部署的机器人共享执行经验，共同改进一个公共策略。
2. **FERT（失败引导的经验检索微调）**：四步——异步收集经验、对经验编码、用失败时的上下文去全队共享的成功经验里检索相关轨迹片段、用这些片段的动作作为监督做带优先级的微调。整个过程不需要额外的专家示范或纠正动作。论文附录还给出了 FERT 改进下界的理论分析。
3. **FATS（容错异步训练系统）**：数据面 SwarmLink、控制面 HotSwarm，协调经验收集、策略优化和策略分发，即使个别机器人中断也不影响整体进度，并处理边云通信。

## 实验设置与主要结果

- 五个真实世界操作任务，每个任务在**未参与训练数据收集**的机器人上评测 120 次。
- 最终策略成功率为 93.3%–99.2%。
- 在每台机器人采集时长固定时，机队越大经验越多，FERT 在评测的各个规模上总体成功率越高。
- 多阶段手机包装任务上，用 96 台机器人学习，成功率从初始化的 79.2% 提升到 98.3%。注意：96 台只是手机包装任务的规模，其他任务只用了 16 或 32 台；79.2% 的起点策略本身是在人工介入下训练的（附录 C.2），成败标签和环境复位也由人工完成（p5–6）。
- 消融实验支持"失败引导检索"这一设计的贡献；系统测量刻画了机队运行中的采集和通信情况。

## 局限与风险

- 项目页的 Code 链接指向通用框架 RLinf，并非 FERT 专用代码。

作者说明目前评估的是五个任务上的任务专用策略，且迁移只验证到同一平台的其他机器人实例。方法依赖专家监督的初始化，且只能从"别的机器人成功过的动作"里学，如果某类失败在全队都没有成功先例，就无从检索。大规模机队实验门槛很高，外部复现困难。

## 工程落地启示

- 对已经批量部署的机器人，经验回流 + 检索式微调是一条低人力成本的持续改进路线。
- 用失败案例当"查询"去找成功样本，是一种简单有效的数据筛选思路，也可迁移到智能体的经验复用。
- 真正落地需要容错的分布式训练系统，论文把系统工程放在和算法同等重要的位置。

## 与相关工作的关系

它与真实世界强化学习/人在环学习（HG-DAgger 等）、机队规模的数据采集、经验回放与优先级学习、以及分布式机器人学习系统都有关。区别在于用机队自身的成功经验替代人工纠正动作，并配套了完整的异步容错系统。
