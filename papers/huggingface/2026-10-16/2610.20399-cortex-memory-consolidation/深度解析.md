## 一句话总结

Cortex 把「记忆巩固（Memory Consolidation）」形式化为：在去掉上下文后仍恢复上下文带来的行为增益（Consolidation Rate, CR），并保留非目标能力（Retention Rate, RR）；方法生成**前瞻查询**预见上下文用途，再把上下文条件输出蒸馏进可合并的 **FFN 低秩（Synaptic）或结构扩展（Structural）** 更新，在多数设定下处于 CR–RR Pareto 前沿。

## 研究问题与动机

上下文能立刻提升表现，但参数不变则上下文一撤增益消失；外置记忆依赖检索，间接相关经验易漏。作者借鉴生物系统巩固（海马快速编码 → 新皮层慢整合），把知识编辑、技能学习、行为引导、知识抑制统一为同一持久化目标：用上下文描述期望改变，用行为增益作参考，而非各任务各套接口。

## 核心方法

- **目标**：对每个更新，M′ 在无 C 时尽量恢复目标查询上的上下文增益，并在保留查询上接近原模型；序列更新还要保住此前有效所学。
- **学什么**：生成 prospective queries + 上下文条件回答作学习目标（不碰 held-out 评测集）。
- **改哪里**：只动 FFN——Synaptic 为已有投影加低秩；Structural 增加非线性特征通道并保持原权重块；对预训练 MoE 用**共享扩展**（router 固定），使每 token 都能走新增参数。
- **怎么学**：上下文条件教师监督无上下文学生（输出 KL + 隐状态 MSE）；序列更新冻结更新前模型、只训新参数；query replay 保留生成查询并用更新前检查点重生成目标，不存旧上下文。
- **测试床**：五任务族——agent 经验巩固、新 API 学习、persona 引导、知识抑制、事实编辑；支持 single / batch / sequential。

## 实验设置与主要结果

骨干覆盖 **4B–120B** 稠密与 MoE，含指令、thinking、多模态（全文以文本输入评测）。对比任务专用、蒸馏、超网络、TTT 等基线。

- 摘要/引言硬数字：在 **14B** 模型上做 **50** 次序列事实编辑后，Cortex-Structural **CR 88.9%**、**RR 99.8%**，相对 AlphaEdit 分别高 **66.2** 与 **3.8** 个百分点。
- Steering（Fig. 5 正文）：两变体约恢复 **95–100%** 上下文增益，流畅度 RR **99–100%**（Gemma3、Qwen2.5）。
- Batch editing：在三个 Qwen 骨干上 CR 约 **80–91%**。
- 消融：相对同时改 attention，仅 FFN 更好；结构扩展即使无 replay 也减轻遗忘；共享 MoE 扩展优于独立扩展；隐状态对齐提升 RR、略降 CR。
- 其他：邻居探针 L1/L2 分数相对 Vanilla 约降 **9–20** 分（0–100 尺），而 BBH 准确率仅降 **0.1–3.3** 个百分点（附录 C 相关表述）。

## 局限与风险

结论中的未来工作暗示现状边界：跨任务持续与大批次巩固仍待加强；结构扩展的剪枝/合并、用超网络从上下文预测结构参数以摊销成本尚未解决。评测上下文为人工构造以拉出显著增益，真实嘈杂上下文巩固难度可能更高。参数写入带来的错误巩固/安全风险需与编辑类工作同样审慎。

## 工程落地启示

- 适合「文档/经验临时进上下文有效，但线上不能每次都带长上下文」的场景：API 手册、persona、局部事实修订。
- 优先试 FFN-only + 可合并更新，便于回滚与多编辑叠加；序列场景务必开 replay。
- 用 CR/RR 成对看，避免只报目标准确率而忽略非目标能力塌陷。作者计划公开 Testbed 与实现（仓库链接已给出）。

## 与相关工作的关系

统一知识编辑、技能学习、行为引导与抑制到 MC 目标下；与上下文蒸馏、持续学习、测试时训练相关，但强调「去掉 C 后仍复用」且每次更新都保留初始非目标能力。相对 AlphaEdit 等编辑基线，在长序列编辑上报告明显更高的 CR 与 RR。
