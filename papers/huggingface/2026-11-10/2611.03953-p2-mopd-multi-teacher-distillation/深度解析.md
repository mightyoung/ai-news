## 1. 一句话先懂它

想把医疗、法律、金融、指令跟随四个「专科老师」模型的本事合并到一个学生模型里，常规做法是让老师逐字批改学生的回答，慢而且会把某一科落下。这篇让学生在训练时还能按比例「借用」老师的参数，用一半步数就超过常规做法的最终成绩，最落后的那一科也补了上来。你做多领域模型合并时可以参考这个思路。

## 2. 值不值得读：五个 C 速览

**类型**：新方法，附带机制分析。**上下文**：接着 MOPD（Multi-teacher On-Policy Distillation，多教师在线蒸馏：学生自己写答案，再让对应领域的老师逐 token 打分）和模型合并（task arithmetic，任务算术：把「老师权重减基座权重」的差值按系数加回基座，不用训练）两条线，最近的前作是 IM-MOPD（训练中定期按验证集规则把落后领域的差值并回学生）和 Open-MOPD。实验协议直接沿用 IM-MOPD。**关键假设**：所有老师和学生必须从同一个基座微调出来，差值才有意义；只测了 Qwen3 的 4B、1.7B 两个规模、四个领域、100 步训练。在这个范围内站得住，换架构或更多老师未验证。**贡献**：一是把「基座+老师差值的线性组合」当成一个可训练模型，系数和权重一起学；二是用投影分析说明增益来自「让学生能走到落后领域老师的方向」；三是三种子、配对比较的扎实实验。**清晰度**：正文清楚，实现细节（梯度裁剪顺序、weight decay 必须为 0）藏在附录 A、B。建议**看到第 5 节**；如果你正在做多专家合并或在线蒸馏，值得自己读原文第 3、4.3 节和附录 B。

## 3. 它在解决什么麻烦

现在不少大模型的做法是先分别训练若干领域专家，再合成一个通才。合成有两条路。第一条是在线蒸馏：每一步让学生对各领域的题目自己生成回答，再让该领域的老师用 teacher forcing（把学生写的前缀原样喂给老师，看老师在每个位置会怎么预测）给出逐 token 的目标。这条路效果好但很重：每一步都要采样、都要跑老师，学生要靠很多步才能一点点爬到每个老师的水平；而且论文和前作都观察到它会「偏科」，某个领域始终跟不上，甚至把起点已有的能力练丢。第二条是模型合并，零训练成本，但合出来的模型没人监督，本文实验里均匀合并只恢复了不到一半的差距（p2，Table 1）。

你在工程里会这样撞上它：团队已经有医疗、法律两个微调好的同源模型，想合成一个上线。直接平均权重，两边都掉分；跑多教师蒸馏，GPU 账单很大，而且训练曲线上法律涨得很好、医疗一直卡着。Table 1（p7）里 1.7B 的 MOPD（TA init）就是这样：其他三科恢复得不错，MedQA 的最差领域恢复只有 32.03（三种子均值），比合并起点的 44% 还低（p6）。

如果这篇的做法成立，你可以在几乎不增加推理成本的前提下（导出的仍是普通权重），用更少的训练步数拿到更均衡的合并模型，并且训练结束时还能从学到的系数里看出学生「最需要哪个老师」。

## 4. 他们怎么做的

**核心思路**：合并后的模型对系数是线性、可求导的，所以「基座+各老师差值×系数」本身就是一个可以端到端训练的模型。P²-MOPD 保留 MOPD 的损失不变，只是把学生每一层的权重改写成「自己可训练的权重 + 各老师差值 × 可学习系数」。老师因此用两种方式帮忙：输出层面照常打分，参数层面提供现成的移动方向（作者称为参数先验，即给优化路径加的偏好，而不是限制模型能表达什么）。

**步骤与部件接口**：

第一步，准备差值。输入是同源的基座和 K 个老师（本文 K=4），对注意力和 MLP 里每个线性投影（q、k、v、o、gate、up、down）算出「老师权重减基座权重」。这些差值冻结不训练，在训练中按模块从内存映射的文件里流式读取（p13）。

第二步，初始化。从均匀合并（每个老师系数 0.25）出发，所有系数初值设为 0.25，学生权重就是合并后的权重（p4，p15）。嵌入层、归一化层和输出头不参与系数组合，照 MOPD 普通训练。

第三步，每个训练步。学生对 128 道题（每领域 32 道）各采一条回答，按领域路由给对应老师打分，奖励是限制在学生前 16 个候选 token 上的反向 KL（衡量学生和老师在同一位置预测分布差多少）（p3，p12）。反向传播一次得到权重梯度 G，然后分两路更新：权重通道用 AdamW（学习率 1e-5、权重衰减 0）；系数通道的梯度就是 G 和每个差值的内积，用 Adam（学习率 1e-2）更新，再把「系数变化量 × 差值」加到权重上（Algorithm 1，p5）。两路各自裁剪梯度，系数梯度取自裁剪前的 G。

第四步，导出。训练结束把系数折进权重，得到普通检查点，推理完全不变（p8）。

影响复现的细节：权重衰减必须为 0，否则「直接更新物化权重」和「更新可训练部分再重组」不再等价，会悄悄压缩差值分量（附录 B，p13）。系数学习率敏感：3e-3 仍有约四分之三收益，3e-2 在 1.7B 上第 50 步后反而低于基线（附录 D，p14）。每次实验 100 步、8 张 GPU（Table 10，p15），GPU 型号论文未说明。

**如果让你复现**，最小骨架是：

```python
tau = {m: [W_k[m] - W_0[m] for k in experts] for m in proj_modules}  # 冻结的老师差值
W = merge(W_0, tau, coef=0.25); alpha = full((K, M), 0.25)          # 均匀合并起点
for step in range(100):
    y = student.generate(prompts)                                   # 学生自己写答案
    loss = mopd_loss(student, route_teacher(prompts), y)            # 老师逐 token 打分
    G = grad(loss, W)
    g_alpha = [[inner(G[m], tau[m][k]) for m in M] for k in K]      # 系数梯度=内积
    W = adamw_step(W, clip(G), wd=0); d = adam_step(alpha, clip(g_alpha))
    W += sum(d[k, m] * tau[m][k])                                   # 系数增量加回权重
```

## 5. 证据怎么看、别被什么忽悠

**表一：Table 1（第 7 页），最终结果。** 想证明：同样从均匀合并出发，P²-MOPD 最终更好也更均衡。怎么测：Qwen3-4B 和 Qwen3-1.7B 学生，四个领域测试集 MedQA、CaseHOLD、FinQA、IFBench；每题温度 1.0 采三次取平均（avg@3）；恢复率以基座为 0、领域老师为 100；三训练种子。结果：1.7B 平均恢复率 P²-MOPD 94.74±0.91，对 MOPD（TA init）80.93±3.02；最差领域恢复 88.01±1.27 对 32.03±10.12。4B 上是 94.85±2.06 对 83.13±9.03，最差领域 89.42±2.54 对 47.22±23.72。说明：提升主要体现在「不偏科」。注意恢复率会放大小差距：1.7B 的平均原始分是 58.72±0.21 对 56.55±0.52，只差两分多（同表），作者也在正文和附录 G 提醒了这一点。

**图一：Figure 1（第 1 页）与 Table 4（第 8 页），速度。** 想证明：一半步数就超过基线的最终水平。结果：1.7B 在第 50 步达到 90.5，已超过 MOPD（TA init）第 100 步的 80.9；每步更慢（167.4 秒对 153.9 秒），100 步总耗时是基线的 1.09 倍，到达目标的墙钟时间上限是基线的 0.55 倍；4B 是 1.24 倍和 0.31 倍。说明：额外开销在更新阶段流式读差值，但采样占大头，所以总时间只多一点。

**表三：Table 3（第 8 页），控制实验。** 想证明：增益来自「医疗老师那个方向」，而不是多了参数。结果（1.7B，最终检查点）：把差值换成同范数随机方向，MedQA 恢复只有 1.4、平均 70.2；只学医疗系数，平均 95.0，接近完整版 95.8；冻结医疗系数，MedQA 回到 24.2。配合 Figure 4（p7）的投影：基线沿医疗方向只走了 +0.03，P²-MOPD 走了 +0.40/+0.42。

**水分检查**：①种子：主方法和主基线都是三训练种子，带标准差，评测再三次采样，比较规范；但 Table 3、Table 6 的多数变体是单次运行。②基线：四个基线都按 IM-MOPD 官方配置跑，同一起点、同一评测脚本，算公平；不过 4B 用的是 IM-MOPD 发布的老师，1.7B 老师是作者按其流程自训的（p13）。③评测：四个公开基准，但没有通用能力回归测试，论文未说明合并后通用能力是否下降。④规模：只到 4B、四个领域、100 步，更长训练下基线是否能追上未知。⑤指标：恢复率分母差三倍（附录 G，p16），平均恢复率的大差距背后原始分差距小。⑥另一种解释：作者用「去掉其他领域只训医疗」排除了「纯粹是领域冲突」的解释（p8），这一点做得好。

## 6. 可信度与核验限定

**主张对照**：①「1.7B 最终平均恢复 94.7% 对 MOPD 80.9%」：Table 1（p7），三种子，证据够，但对照对象是同一合并起点的 MOPD（TA init）。②「一半步数超过基线最终值」：Figure 1、Table 4、附录 G，每个种子对都成立，证据够；检查点间隔 25 步，时间是上限值。③「最差领域从不到一半升到接近 90%」：Figure 3、Table 1，证据够。④「代码已公开」：不成立，见下。

**核验限定**（原样合入核验报告）：
- 94.7% vs 80.9%：Qwen3-1.7B 学生，MedQA/CaseHOLD/FinQA/IFBench 四域平均恢复率（以基座为 0、领域教师为 100），P²-MOPD 94.74±0.91 vs 同一 TA 起点的 MOPD 80.93±3.02，三种子均值（Table 1 p7）
- 机构：第一单位是 Adelaide University，StepFun 是第二单位（p1 脚注）；HF 页面只标 StepFun
- 论文写代码已公开，但 github.com/SinuoWang/P2-MOPD 在 2026-11-10 只有 README 和图片，尚无代码

**打折提醒**：对外引用时说「恢复率」不要说「准确率」，原始分只高两分多；Figure 1 里的 90.5 是第 50 步的值，不是最终值；不要说「可复现」或「开源」。

## 7. 你可以怎么落地

**今天就能试**：不用新机器。如果你手上有多领域合并或蒸馏的评测记录，按论文的口径补一张表：每个领域算「（合并后得分 − 基座）/（老师 − 基座）」，同时列平均恢复率、最差领域恢复率和原始平均分。验收：最差领域明显低于平均（比如低二三十个点），说明你也有偏科问题，值得考虑本文思路；如果三列都很接近，这篇对你帮助不大。

**要有数据或机器再试**：前提是一组同源的领域专家（同一个基座微调出来）、在线蒸馏框架和 8 卡级别的 GPU；论文 1.7B 一次 100 步约 4.9 小时（Table 7，p13），三种子加基线一共约十来次运行。分阶段：先只做「冻结权重、只学系数」（最省事，看能否比均匀合并好），再上完整双通道；系数学习率从 1e-2 起扫 3e-3、3e-2。验收：同一合并起点、同种子配对，最差领域恢复和平均原始分都要比 MOPD（TA init）高。

**暂时别碰**：不要把它用在非同源模型（不同基座、不同架构）上，差值没有定义；也不要指望直接拿到官方代码，目前仓库是空的。权重衰减非 0 的训练配置下等价性不成立（p13），直接套会出偏差。

## 8. 和你已有知识的挂钩

它像给优化器装了「快捷方向键」：常规训练只能一小步一小步摸索，这里把老师的差值当成几个预设方向，一个标量就能让整个模块朝老师那边整体平移，作者也把它解释成一种预条件（放大梯度在特定方向上的分量）。和 AdaMerging 这类「学合并系数」的方法最大的区别是：权重本身也一直可训练，模型不被困在几个老师差值张成的空间里；和 IM-MOPD 的区别是系数由蒸馏梯度连续学出来，而不是按验证集规则定时硬合并。

## 9. 存疑与代价

**局限**：论文没有单列局限一节。读出来的有：只测 Qwen3 两个小规模和四个领域；第五个领域 τ²-bench 因为需要付费 API 被去掉（p5）；没有通用能力回归；多数消融单次运行；FinQA 在多数配对里略低（p6）。**复现条件**：代码仓库无代码、无 LICENSE；4B 老师来自 IM-MOPD 发布版本，1.7B 老师需自己训练（p13）；训练数据用 IM-MOPD 数据管线，共 65,075 条提示（p13）。**成本**：每次 100 步、8 GPU，4B 约 6.51 小时、1.7B 约 4.90 小时（Table 7，p13），每步需要同时持有多份老师检查点。**出处**：预印本，未同行评审；第一单位是 Adelaide University，不是 HF 页面写的 StepFun。

**论文没回答、但决定你要不要动手的 3 个问题**：老师数量从 4 个增加到十几个时，系数会不会互相抢、开销会不会明显增大？训练到几百步以后，基线是否能追平，优势是否只体现在早期？合并后的模型在通用对话、代码等未参与领域上掉不掉分？
