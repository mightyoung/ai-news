# WeVisOne-VL：从物体到像素的统一视觉感知

**WeVisOne-VL: Unified Visual Perception from Objects to Pixels**

- arXiv：https://arxiv.org/abs/2610.31329 · HF：https://huggingface.co/papers/2610.31329
- 点赞数：243（2026-10-26 09:00 北京时间抓取，HF 2026-10-23 批次）
- 机构：WeChat Vision, Tencent Inc.（论文署名）
- 代码/权重：https://github.com/Tencent/WeVisOne-VL · [4B](https://huggingface.co/tencent/WeVisOne-VL-4B) · [2B](https://huggingface.co/tencent/WeVisOne-VL-2B)（apache-2.0，无需申请）

## 一句话总结
腾讯微信视觉团队在 Qwen3-VL 上做出 2B/4B 两个尺寸的"视觉全能感知"模型，用坐标 token + 一个 `<OBJ>` token 接轻量像素解码器，把检测、指代定位、计数、OCR、分割、抠图（matting）统一成结构化的下一个 token 预测，并开源权重。

## 研究问题与动机
通用 VLM 擅长"看懂图在说什么"，但在细粒度感知上不可靠：会幻觉出不存在的物体、误解陌生的指代描述、漏掉不显眼的实例。专用检测/分割模型（GroundingDINO、SAM 等）精度高但接口割裂。论文想要的是：一个自然语言接口、一次推理，从点、框到掩码、alpha matte 任意粒度都能输出，并且在目标不存在时能正确拒答。

## 核心方法
1. **数据引擎（WDE）**：用知识图谱组织类别概念和组合式指代表达，组合多个定位专家（SAM3、自研开放词表检测器、Qwen3-VL 做查询–区域核验等）生成候选并交叉验证，再扩展到二值掩码；抠图另训一个专用标注器给连续 alpha 监督；用模型错误回流指导采集、纠错和难例采样。训练数据约 1 亿张带细粒度标注的图像。
2. **模型结构**：用专门的坐标 token（`<0>`–`<1000>`）编码归一化坐标，自回归生成标签和坐标；对密集任务，每个框后输出一个 `<OBJ>` token，其隐状态作为实例表征，与共享 ViT 的多层特征一起送进轻量像素解码器，在全图上出掩码，不依赖外挂大分割模型。
3. **训练流程**：三阶段课程式 SFT（任务对齐 → 高分辨率与密集感知 → 像素级任务），然后挑 SFT 模型最不确定的样本做多任务混合的 GRPO 强化学习，以提升定位精度并抑制重复或幻觉预测。

## 实验设置与主要结果
- 覆盖 30 多个基准，检测类指标采用 F1（因为生成式 VLM 没有校准过的置信度，AP 不适用），报告 IoU=0.5、0.95 及 0.5–0.95 平均。
- 表 2 中 COCO 零样本 F1@0.5：WeVisOne-VL-4B 为 74.0、2B 为 72.6，高于 Qwen3-VL-4B 的 66.6 与专用检测器 GroundingDINO-T 的 69.8。论文称在 Dense200、VisDrone 等小目标、密集场景上提升尤其明显，且在严格的 IoU=0.95 下也保持优势——但并非每格都第一：IoU=0.95 时 COCO 上低于 GroundingDINO-T（19.5 对 23.0），LVIS 上低于 LocateAnything-3B（28.8 对 31.1）。
- 读表注意：对比的 Qwen3-VL-4B 正是其底座；同表 Rex-Omni-3B 为 72.0，与 4B 的 74.0 只差 2 个点。
- 结论部分称：均值检测 F1 和计数准确率优于同尺寸 VLM，文本定位和指代定位进步，指代分割和抠图超过所评测基线；定性例子展示了拥挤场景下逐实例定位和目标缺失时的拒答。

## 局限与风险
作者自述：通用训练数据有限，可能削弱相对底座的通用能力；为推理效率不做思维链，复杂推理任务受限；目前只支持单轮预测。基准里的指代描述清晰规范，而真实用户指令往往含糊，意图理解仍是难点。另外 F1 指标与传统 AP 不能直接对比，读表时要注意。

## 工程落地启示
- 想把"检测+分割+OCR"合成一个小模型部署，2B/4B 规模和开源权重很有吸引力，可作为 GUI agent、具身感知前端或内容审核的统一视觉模块。
- "坐标 token + 实例 token 接解码器"是给 VLM 加密集输出的低成本做法，可借鉴。
- 数据引擎里"多专家候选 + VLM 核验 + 错误回流"的套路，对自建标注管线很有参考价值。

## 与相关工作的关系
延续 Rex-Omni、LocateAnything 等"用 VLM 做检测"的路线，并把像素级输出（类似 LISA 一类用特殊 token 接分割头的做法）并入同一模型；底座是 Qwen3-VL，强化学习部分沿用 GRPO。
