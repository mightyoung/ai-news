## 1. 一句话先懂它

很多人用「学生自己采样、老师逐步纠正」的在线策略蒸馏，把多个强化学习专家合成一个模型，分布内分数能追到老师的九成以上；但这篇发现：换到更难或要拼能力的题上，学生仍可能比蒸馏前的底模还差一截——分布内接近满分，并不等于泛化已经接到手。

## 2. 值不值得读：五个 C 速览

**类型**：测量分析为主，附带两种修补尝试（几何补丁、保底模回放）。**上下文**：接着 OPD / MOPD（多教师在线策略蒸馏）在数学、问答、多轮代理上的近乎满分报告，以及把各域 RL 专家再蒸馏成一个学生的工业后训练流水线。**关键假设**：把「训练时直接监督过的分布」叫 IND（in-distribution，分布内），把更难题或能力组合叫 OOD（out-of-distribution，分布外）；学生与多数教师共享 Qwen3-8B 底模。口径清晰，但 IND/OOD 边界依赖作者按教师相对底模的表现来划分（附录 A.2.1）。**贡献**：① 外推与组合两类设定上，定量拆开「IND 很漂亮」与「OOD 仍遗忘」；② 指出教师能力与数据覆盖是两个瓶颈，一起放松后可消掉实验里的 OOD 遗忘；③ 用更新几何解释为何 (M)OPD 比混合 RL 温和，并试 Procrustes 注意力补丁与保底模回放。**清晰度**：图表多、数字密，主结论在摘要就写清。建议**看到第 5 节**；若你正在做多专家蒸馏合并，值得自己读 §5–8。

## 3. 它在解决什么麻烦

现在常见做法是：先在数学、代码、工具、长上下文上分别 RL 出专家，再用 OPD/MOPD 把他们「焊」回一个学生。看板上看训练域指标很快贴老师，大家就当巩固成功。

麻烦是：贴老师的往往是训练域。你换成更难的数学竞赛、或「长上下文 + 写代码」「数学 + 长文档」这种要拼能力的题，学生可能仍低于蒸馏前的底模，也远低于擅长该组合的老师。于是产品上会出现「单科都涨了，综合题却没涨甚至倒退」。

若结论成立，后训练验收就得把 OOD 留存和组合题单列，而不能只看蒸馏集或同分布基准的贴合度。

## 4. 他们怎么做的

**核心思路**：OPD 让学生在自己生成的轨迹上，逐步对齐老师的下一 token 分布（反向 KL）；MOPD 再按任务混合多个老师。作者问的不是「IND 能不能贴老师」（前人已报近乎满分），而是贴合之后，外推与组合能力有没有一起过来。

**教师两类**（§3.1，第 3 页）：① self-RL specialist——从同一 Qwen3-8B 底模出发，用 GRPO（组相对策略优化）在单域上训出的专家，再蒸回同底模初始化的学生；② external generalist——例如用更强的 Qwen3-32B 当老师，模拟强教弱。对照方法是同数据配比的混合 RL（mixed RL）。

**两种泛化**（§3.2）：外推——同能力但超出监督难度（如 GSM8K/MATH/DAPO 训，AIME 等更难集测）；组合——分能力监督，测需要拼在一起的任务（代码+代理→SWE-bench；数学+长上下文；代码+长上下文）。

**数据与评测**（§3.3）：数学用 GSM8K、MATH、DAPO 训，评 MATH500、AMC23、AIME24/25 等；代码、BFCL 工具、DocQA 长上下文等同理。合成推理预习实验用操作步数控制难度（§4，Fig.1，第 5 页）：IND 蒸馏比约 93–104%，OOD（15–17 步）只剩 76–86%。

**修补**（§8）：① Procrustes-attention patching——把 OPD 相对底模的更新与 RL 老师更新做正交对齐，减掉「对 IND 贡献小、却伤 OOD」的分量；② base-preserving replay——蒸馏时回放底模行为以显式保 OOD。

**如果让你复现**（单教师 OPD 骨架）：

```python
student = copy(base_qwen3_8b)                 # 与 self-RL 教师同底模
for step in range(num_steps):
    prompts = sample(D_train)                 # 如 GSM8K / MATH / DAPO
    ys = student.generate(prompts)            # 学生自己采样（on-policy）
    loss = 0
    for x, y in zip(prompts, ys):
        for t, token in enumerate(y):
            h = (x, y[:t])
            loss += KL(student(.|h), teacher(.|h))   # 式 (1)，反向 KL
    loss.backward(); optimizer.step()
# 验收：IND（训练域基准）与 OOD（更难/组合基准）分开报，相对 base 与 teacher
```

MOPD 把上式按任务加权混合（式 2）；混合 RL 则在同混合数据上直接最大化奖励。论文未在正文展开全部超参，细节见附录 A。

## 5. 证据怎么看、别被什么忽悠

**图一：摘要区间 + Figure 2（第 1–2、6 页），外推：IND 贴合 vs OOD 遗忘。** 想证明「分布内接近老师 ≠ 分布外保住底模」。设定：Qwen3；OPD/MOPD 相对教师的 IND 均分达 **96.04–102.73%**，但 OOD 均分仍比 base 低 **2.45–16.25%**（摘要/引言，物理页 1–2）。Fig.2 在 GSM8K / MATH / DAPO 三块训练下，把基准从左（偏 IND）排到右（偏 OOD）；紫色 OPD 线在多数 OOD 点介于底模虚线与教师实线之间——比教师忘得少，但仍低于底模。AIME 报 avg@8。说明：只盯训练域会误判巩固成功。

**图二：组合设定（引言 + §6，Fig.5–7，第 2、7–8 页）。** 想证明「单科都涨 ≠ 组合会涨」。三组设定上，MOPD 组合任务作为 OOD，仍比最佳教师低 **18.19–24.34%**；IND 相对 base 可提升 0.48–22.46%（p1–2）。正文汇总：MOPD 组合题均分约低于最佳教师 23.82%，略好于混合 RL（低 26.10%）（§6，第 7 页）。长上下文+数学例（Fig.6）：MOPD 约达教师 IND 均分的 96.0%，组合题仍低最佳教师约 24.3%。说明：能力是「焊」上了分项，不自动变成组合技能。

**图三：Figure 8–10（第 9–10 页），瓶颈与修补。** 想证明可以缓解。教师能力（A）与数据覆盖（B）是两个瓶颈：只换强老师、数据仍窄，学生 OOD 仍可低于 base；两者一起放松（如 Qwen3-32B 监督 GSM8K 并混 10% OpenR1）后，实验中可消掉 OOD 遗忘并在部分集超过 base（Fig.9）。补丁：α=0.40 的 Procrustes 注意力补丁把 AIME25 avg@8 从 60.83% 拉到 65.00%，GSM8K 仍 93.48%（Fig.10，第 10 页）。回放相对纯 OPD 在 8 个 OOD 基准里改进 5 个（§8 引言，第 2 页）。说明：问题可工程干预，但还不是「一键通用解法」。

**水分检查**：① 头条区间来自摘要/引言汇总，不是单表一行，引用时要带「跨设定范围」。② 主骨干 Qwen3-8B，外推数学为主；组合题含 SWE-bench 等，但随机种子与误差条在正文图注里不总完整。③ IND/OOD 划分部分依赖教师相对 base 的表现，换划分可能移动边界（作者在附录承认）。④ 几何解释（更新范数更小、谱更集中、与单教师更新更共线，Table 1 第 9 页）是相关观察，作者写明因果尚未建立。⑤ 与混合 RL 对比时强调同配比、未额外调任务权重——公平，但可能未挖出混合 RL 最优。

## 6. 可信度与核验限定

**主张对照**：①「IND 近乎满分可掩盖 OOD 缺口」：摘要区间 + Fig.2/4，在 Qwen3 数学外推上充分。②「组合能力不自动出现」：三设定 + 18.19–24.34% 区间，充分但依赖组合题定义。③「同时放松教师与数据可消遗忘」：Fig.8–9，方向清楚，场景仍偏数学。④「补丁/回放有用」：Fig.10 与五/八 OOD 改进，属初步阳性。

**核验限定**（原样合入）：
- 外推设定：(M)OPD IND 达教师 96.04–102.73%，OOD 仍比 base 低 2.45–16.25%（Qwen3；摘要/引言 p1–2）
- 组合设定：MOPD 组合任务 OOD 比最佳教师低 18.19–24.34%（p1–2）
- 项目页 https://yichenzw.com/opd-generalization.github.io/ ；论文 arXiv nonexclusive-distrib 1.0

**打折提醒**：对外说「蒸馏到老师的 100%」必须加「IND / 训练域」；说「比 base 低最多约 16%」是 OOD 均分相对降幅区间，不是所有题都掉 16%。不要把补丁的 +4.17 个百分点 AIME25 说成通用涨点。

## 7. 你可以怎么落地

**今天就能试**：不用重训。把你现有的蒸馏/合并验收表拆成三列：训练域 IND、同域更难 OOD、跨能力组合题。用同一个学生检查点各跑一遍，算「相对 base 的差」和「相对老师的差」。验收：若 IND 已 ≥95% 教师，而 OOD 仍明显低于 base，就与这篇主结论同型—— consolidaton 看板不能只看 IND。

**要有数据或机器再试**：有 8B 级训力与现成 RL 专家时，按附录配方复现一臂「单域 OPD vs 教师 vs base」，再试「强老师 + 扩数据」或蒸馏期加一小股底模回放。验收：OOD 是否回到 ≥ base，同时 IND 掉幅是否可接受（文中回放称 IND 仅小幅下降）。

**暂时别碰**：不要因为 IND 贴合就下线底模能力回归测试；也不要在没有组合题的情况下，用这篇证明「MOPD 已经解决多能力合并」。几何补丁涉及按层对齐注意力更新，实现与调 α 成本不低，证据仍偏单点，不适合直接当生产默认。

## 8. 和你已有知识的挂钩

它像「把多门选修课的高分笔记复印进同一本复习资料」：复印得很像（IND），一上综合闭卷（OOD/组合）仍可能不如复习前的自己。和普通离线蒸馏最大的区别是：轨迹来自学生自己（on-policy），信号密、收敛快，也更容易让人误以为「已经把老师的泛化整杯喝下」。

## 9. 存疑与代价

**局限**：主结果偏 Qwen3；IND/OOD 边界有操作定义；组合题是否代表真实产品工作流仍可争；补丁与回放是探索性阳性。**复现条件**：项目页可访问；核验时未见单独代码 LICENSE；论文为 arXiv 非独占分发。**成本**：多教师、多设定、含 32B 老师与 SWE-bench 级评测，个人需缩到单域外推才能起步。**出处**：预印本；芝加哥大学一作，工作完成于 ByteDance。

**论文没回答、但决定你要不要动手的 3 个问题**：换 Llama 等家族，16% 级 OOD 缺口是否同量级？补丁在组合题上是否也稳定？工业流水线里若老师本身就在 OOD 上低于 base，蒸馏最多能救回多少？
