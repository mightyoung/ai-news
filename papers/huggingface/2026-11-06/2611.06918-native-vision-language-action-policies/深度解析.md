## 1. 一句话先懂它

大多数机器人「看-说-动」模型先用独立视觉编码器把图像压成特征，再谈动作。这篇去掉这个编码器，让像素和文字在同一个骨干里一起算，动作头还能从浅层到深层多处读特征，仿真里抓放更稳，真机也能跟得上。

## 2. 值不值得读：五个 C 速览

**类型**：新方法（结构上无独立视觉编码器的 VLA）加受控对比实验。**上下文**：接着 OpenVLA、π0 / flow-matching 动作头、encoder-free VLM（NEO 系列、Fuyu 等）以及 LIBERO / LIBERO-plus / RoboTwin。**关键假设**：轻量 patch 卷积足以把像素送进骨干；动作专家读多层 KV 缓存；对比骨干（Qwen3-VL、Gemma-3）用同一动作专家与机器人语料。预训练差异作者自己承认，不能把增益全归给「无编码器」这一条。**贡献**：一是原生像素入口 + 共享视觉-语言骨干 + flow-matching 动作专家；二是受控对比显示冻结骨干优势最大；三是层图消融证明浅层对控制重要。**清晰度**：图 1–2 把三种 VLA 设计画清楚；表 2/4 数字干净。建议**看到第 5 节**；做 VLA 落地的人值得自己读 §5.1–5.2 与层探测。

## 3. 它在解决什么麻烦

主流 VLA（Vision-Language-Action，视觉-语言-动作策略）默认：CLIP/SigLIP/DINOv2 先压缩图像，语言骨干和动作头只看见编码器终点。抓取、插拔、贴边却往往依赖局部几何、边界、深度和细微状态变化——这些信号最容易在抽象压缩里丢。

你会在什么时候撞上？用开源 VLA 微调机械臂，指令语义对了，但夹爪总差几毫米；换光照或相机位姿就掉成功率；或者你冻结视觉、只训动作头，发现怎么也上不去。作者问的是：动作策略该不该继承一个固定的视觉终点，还是该直接摸到「正在演化的视觉计算」？

若假设成立，控制可以读浅层细节与深层语义，冻结骨干也能有很强迁移；换背景、相机、语言表述时更稳。对工程团队，这意味着「只堆更大的视觉编码器」未必是最优解，接口怎么设计、动作头读哪些层，可能同样关键。

## 4. 他们怎么做的

**核心思路**：不要把视觉当成「算完再交给 LLM」的黑盒；让图像 patch 与指令 token 在同一骨干里逐层共演化，动作专家从选定层读 KV，相当于把「读哪一层视觉」变成显式超参。

**结构**（图 1–2，第 2–3 页）：轻量卷积 patch embedder 把像素映到骨干 token 空间；文本一并进入；40 层、约 2B 参数的 encoder-free 骨干；窄的、随机初始化的动作专家用 flow matching（流匹配：学习从噪声到动作的速度场，输出连续动作块）读缓存的 keys/values。

**层图选择**（§ 方法，约第 5 页）：`skip-28` 在 40 层里近似均匀抽 28 层；`end-28` 只读 12–39 深层；`full-40` 全读。默认偏 `skip-28`。

**训练三阶段**（约第 6 页）：①冻结骨干，训动作专家与条件模块，113,400 step；②同机器人预训练语料再 75,000 step；③内部动作数据再 75,000 step。公平对比时各骨干先在 Open X-Embodiment 上同设定预训练。下游 LIBERO 报告最终 **30,000** 步检查点。

**如果让你复现**，骨架如下：

```python
# 前缀：多视角像素 -> patch embed；指令 -> text tokens；拼进 NEO 骨干
prefix = neo_backbone(patch_embed(images), text_tokens)   # 缓存每层 K,V
# 动作专家：按层图 M 读选定层，预测 flow-matching 速度场
v = action_expert.read_kv(prefix.kv, layers=M)            # 如 skip-28
actions = integrate_flow(v, noise, n_euler_steps=10)      # 连续动作块
# 训练：先冻骨干只训 expert，再按阶段解冻；损失为 flow-matching 目标
loss = flow_matching_loss(v, expert_actions, robot_state)
```

公平对比段里，各骨干都先在 Open X-Embodiment 上同设定预训练约 75k iters，再接到同一动作专家（正文约第 7 页）。作者还做了层替换探测（Figure 4）：逐层扰动动作专家读到的 KV，发现对控制关键的信号往往不在最后一层才出现。论文对真机伺服细节与全部数据配比未在正文穷尽；以开源仓库为准。

## 5. 证据怎么看、别被什么忽悠

**表一：Table 2（第 7 页），骨干对比。** 想证明原生骨干优于同设定 encoder-based。LIBERO 四套件，最终 30k 步，平均约 **2,000 episodes**（每套件 500）。冻结骨干仅训 action expert：NEO-VLA 2B **90.9%**，Qwen3-VL 2B **79.5%**，Gemma-3 4B **84.5%**。全微调 NEO **95.3%**。说明：差距在「冻骨干」时最大，说明预训练出的视觉表征本身更贴控制；全微调缩小但未抹平与「只换接口」叙事的对照（表 3 显示给 Qwen 直接喂早期特征也凑不齐）。

**表二：Table 4（第 8 页），层图消融。** 想证明浅层有用。每配置 **2,000 rollouts** @ 30k。冻结：skip-28 **90.9%** vs end-28 **86.7%**；全微调：**95.3%** vs **92.5%**。说明：只读深层会丢控制信号；均匀跨层更好。

**表三：真机 Table 10（第 11 页）。** 三任务×20 trials（10 域内 + 10 域外），各方法同 50 条示教微调。NEO-VLA 2B：12/20、17/20、13/20；π0.5 3B：10/20、14/20、13/20；StarVLA 更低。说明：头条仿真结论有真机方向一致性，但试验量小，不作主核验数字。

**水分检查**：①头条数字来自仿真 LIBERO，不是真机。②主表未给多种子误差条，无法判断波动。③作者承认预训练与容量差异，不能把 90.9% vs 79.5% 单因归因于「去掉编码器」。④真机每任务仅 20 trials，只作方向印证。⑤动作预训练含 Open X-Embodiment 等大规模语料，复现门槛高；延迟表在单卡 3090 上测，部署另算。⑥另一种解释：原生骨干的优势也可能来自 NEO 系列的图文预训练配方，而非结构本身——表 3 的「给 Qwen 直接接早期特征」实验部分回应了这一点，但仍未穷尽。

## 6. 可信度与核验限定

**主张对照**：①「原生骨干在受控对比下更强」：Table 2，证据充分（仿真）。②「浅层跨层读取优于只读深层」：Table 4，证据充分。③「分布偏移更稳」：LIBERO-plus 等表 5，方向支持但非本条头条。④「真机可迁移」：Table 10，小样本定性偏强。

**核验限定**（原样合入）：
- 冻结骨干 LIBERO 平均成功率 90.9%，对比 Qwen3-VL 2B 79.5%、Gemma-3 4B 84.5%（Table 2 p7；最终 30k 步，平均约 2000 episodes）
- 全微调平均 95.3%；skip-28 vs end-28：冻结 90.9% vs 86.7%，全微调 95.3% vs 92.5%（Table 4 p8，每配置 2000 rollouts）
- 仿真 LIBERO；代码 Apache-2.0（EvolvingLMMs-Lab/NEO）；论文 CC BY 4.0

**打折提醒**：对外引用 90.9%/95.3% 必须带「LIBERO 仿真、30k 步、约 2000 episodes」。不要说成真机 SOTA；真机数字请单独引用 12/20 等并注明试验次数。

## 7. 你可以怎么落地

**今天就能试**：打开 https://github.com/EvolvingLMMs-Lab/NEO ，对照图 1 画清你现有 VLA 属于 encoder-based 还是 native；若你在用「冻视觉、只训动作头」，记下是否只读最后一层特征。顺便在 LIBERO 文档里确认自己的评测是按套件平均还是只报 Long。验收：列一张「读哪些层」清单，对照 skip-28 vs end-28；并写明将用约 2000 episodes 量级对比，避免小样本自嗨；并写明将复现 Table 2 的冻结设定。

**要有数据或机器再试**：有多卡与 LIBERO 仿真时，按仓库跑冻结骨干 30k 步，复现 Table 2 量级；再做 skip-28/end-28 消融。验收：平均成功率是否接近 90.9%/86.7%。真机需 50 条级示教与安全围栏，另算。

**暂时别碰**：没有仿真基建时不要从零复现三阶段预训练；也不要把「去掉编码器」当成无脑升级——表 3 显示「只是接到更早特征」不够，表征怎么预训练更关键。

## 8. 和你已有知识的挂钩

它像相机 ISP：有人把 ISP 封成黑盒只出最终 JPEG，有人把中间 pyramid 也开放给后续模块。NEO-VLA 属于后者。和 OpenVLA / π0 最接近路线的区别：不是换扩散/流匹配头，而是**取消独立视觉编码器终点**，让动作头跨层读原生视觉计算。

## 9. 存疑与代价

**局限**：预训练差异无法完全剥离；主表无误差条；真机样本少；LIBERO 对强方法已偏「顶满」。**复现条件**：代码 Apache-2.0，权重与数据在 HF，论文 CC BY 4.0。**成本**：大规模机器人预训练 + 30k 下游步，单卡爱好者难从头训。**出处**：NTU S-Lab 等，预印本。

**论文没回答的 3 个问题**：换另一套 encoder-free 预训练配方，优势还在吗？真机大样本、多随机种子呢？层图能否按任务自适应而非固定 skip-28？
