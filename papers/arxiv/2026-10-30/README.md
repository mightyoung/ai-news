## 为什么选这 3 篇

- **37741（Agent 安全）**：Agent 正在普遍获得执行 shell 命令的权限，这篇把「预训练数据投毒」直接连到「Agent 在用户机器上执行恶意命令」，且后训练流程是干净的，说明仅靠后训练对齐不足以兜底；作者阵容（Anthropic Fellows / Anthropic，含 Carlini；第一单位为 UC Berkeley）和开源代码让结果更可复查。
- **37719（训练动力学 / 后训练）**：给 SFT、DPO、RLVR 的「小改动大效果」一个可计算的统一量尺，并顺带给出 bf16 主副本、DARE 合并等工程上能直接用的结论，和 10/27 归档的「VLA 微调缺 fp32 主副本」一文可对照阅读。
- **38027（具身智能 + 编程 Agent）**：把人形机器人控制拆成「冻结的通用运动底座 + 用代码写的技能」，让编程 Agent 无需再训练策略就能组合出新技能，并有 G1 真机的定性演示（未报告试验次数），是 VLA/具身与 Agent 两条主线的交汇点。
