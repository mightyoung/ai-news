## 1. 一句话先懂它

用强化学习练推理时，每道题固定采很多条回答很浪费：简单题采满也没梯度，难题又不够。这篇把「这道题该采几条」交给共形预测（一种不依赖分布假设的不确定度证书）来决定，容易的早停、难的加采，训练时平均少采很多条，准确率还能和固定大预算差不多。

## 2. 值不值得读：五个 C 速览

**类型**：新方法，带有限样本保证和系统实验。**上下文**：接着 GRPO，以及 AERO、Reinforce-Ada/Est、GDRO 等自适应 rollout 启发式；理论侧接 split conformal prediction 与 APS。**关键假设**：要有可验证器（对错可判）；校准集与训练集可交换；代码任务用「首次成功位置」分数，闭式答案用 APS。有 verifier 的数学/代码 RL 场景下站得住。**贡献**：一是把自适应组大小写成共形校准问题；二是 APS + first-success、自动 δ、周期重校准等工程件；三是在六基准上相对 G=32 的 GRPO 节省训练 rollout 49–70%，跨家族最高 82%。**清晰度**：方法节密但有 Algorithm 1；局限写得老实。建议**看到第 5 节**；若你正在烧固定 G 的 GRPO 算力，值得自己读原文并跑开源仓库。

## 3. 它在解决什么麻烦

GRPO 对每个 prompt 采固定 G 条回答，用组内相对奖励当优势。G 太大，简单题全对或方差接近零，白烧算力；G 太小，难题可能一条正确轨迹都采不到，正信号缺失。已有自适应预算方法用奖励方差、难度模型等停采，但规则偏启发式，策略一变就容易漂，也没有有限样本意义上的「别过早停」证书。

你会在什么时候撞上？比如 GSM8K 一类题难易差很大，你把 G 设成 32，日志里大量题前几条就全对了；或者 HumanEval 上固定 G 吃满显存，却仍有题零成功。如果 C-GRPO 真管用，同样的训练步数里平均每题少采很多条，墙钟和 GPU 小时下降，而 pass@1 仍落在二项噪声范围内与强基线持平。它还顺带做成一种自步调课程：策略变强后阈值变紧，算力自动挪到仍难的尾巴上，而不必手写难度课表。

## 4. 他们怎么做的

**核心思路**：对每个预算档 k∈K，先用校准集算出一个「非一致性分数」的分位数阈值；训练时从最小 k 开始采，一旦共形预测集缩成单元素（模型在该预算下「有统计意义上的自信」），就停。于是容易题早退，难题走到更大 k。

**两类分数**（第 4 页）：闭式数学/科学用 APS（Adaptive Prediction Sets）：看正确答案在经验频率排序里要累积多少质量才被盖住，并加一点均匀随机使分数连续。代码题几乎每条字符串都独特，APS 会退化，于是用 first-success score：第一条通过单测的样本落在预算的几分之几；从未通过则记 1。

**校准与自适应组**（第 4–5 页）：在与训练不相交的校准集上，每个 k 采到 Kmax，算 q̂_k。训练时两阶段生成：先探最小 k；未形成单例就按网格扩采。组大小变化后，优势在整批上再标准化，避免大组主导梯度。每 Δcal 步用当前策略重校准；δ 还可按当前最大预算求解率自动设定，避免早期阈值塌成「永远采满」或「永远早停」。

**实验骨架**（§5.1，第 8 页）：主表骨干 Qwen2.5-7B-Instruct、step 300；LoRA r=16；校准 ncal=200；测试 ntest=200–400；预算网格 K={2,4,8,16,32}。六基准含 GSM8K、MATH-500、MATH-Algebra、GPQA-Diamond、HumanEval、MBPP。

**如果让你复现**，骨架如下：

```python
# 校准：对每个 k in K，在 D_cal 上采 Kmax，算 APS 或 first-success 分数的 (1-δ) 分位 → q_hat[k]
for step in range(num_steps):
    for x in batch:
        k_used = Kmax
        for k in K:                               # 从小到大
            samples = policy.sample(x, k)         # 可增量扩采
            if is_singleton_conformal_set(samples, q_hat[k]):
                k_used = k; break
        advantages = grpo_adv_batch_norm(samples) # 组内相对 + batch 标准化
        loss += cgrpo_loss(samples, advantages)
    if step % Delta_cal == 0:
        q_hat, delta = recalibrate(policy, D_cal) # 周期重校准 + 可选 auto-δ
```

## 5. 证据怎么看、别被什么忽悠

**表一：Table 1（第 9 页），六基准省 rollout。** 想证明相对固定 G=32 的 GRPO，训练 rollout 大幅下降且准确率不塌。Qwen2.5-7B-Instruct、step 300；Savings=1−k̄_train/32，只计训练 rollout，校准成本另见 Table 10。结果：六基准相对固定预算 GRPO（G=32）训练 rollout 降 49–70%——例如 HumanEval 49%（k̄=16.3）、MATH-500 50%、GPQA-Diamond 70%、GSM8K 68%（k̄=10.4）。作者称 pass@1 相当或略高、差异在二项噪声内。

**表二：Table 2（第 9 页），对比动态基线。** 想证明不只是「比傻大的 G=32 省」。同设置下 C-GRPO 在 GSM8K/HumanEval/MBPP/MATH-500 的 pass@1 居前或并列，且 k̄_train 最低（GSM8K 上 k̄=10.4，相对静态 32 与动态基线 ≥14.8）。作者写与最强基线差距 0.4–2.4 个百分点，落在单次运行约 2.5–3.5 个百分点标准误内，因此主张是「等准确率、少算力」。

**图/跨模型：第 9–10 页与 Figure 3。** 跨模型家族最高省 82%：GSM8K 上 Llama-3.1-8B-Instruct，k̄=5.7。Figure 3 显示累计 rollout 相对 k=32 天花板少约 59.8%（文内写 saved 5738 rollouts）。校准会带来墙钟开销，Table 10 设定下净加速约 3.07×（第 10 页）。

**水分检查**：①多数主结果是单次运行；更长程与更强基座有补充（1,000 步、3 seeds 等在附录）。②Savings 默认不含校准 rollout，对外引用要说「训练 rollout」。③需要 verifier；无金标/无执行环境时方法不适用。④理论保证针对固定策略与新鲜校准拆分；线上循环复用校准题并自适应选 δ，作者承认部署环与定理假设有缝，并用 disjoint split / Theorem 5 讨论修补（§5.7）。⑤LoRA、4–8B、300 步是主舞台。⑥固定 G 对照：作者在相同管线下扫 G=8/10/16/32/128，GSM8K 上静态 pass@1 从 52.8 升到 55.3（G=128，44.5 GPU-h），而 C-GRPO 为 57.2（约 3.8 GPU-h）；说明省算力不是「偷偷用了更大有效 G」这么简单，而是把预算花在更需要的题上（第 9 页）。

## 6. 可信度与核验限定

**主张对照**：①「相对 G=32 训练 rollout 降 49–70%」：Table 1，证据充分，须带骨干与步数。②「pass@1 持平或略高、在噪声内」：Table 2，作者自述充分，但不宜吹成显著涨点。③「跨家族最高省 82%」：GSM8K + Llama-3.1-8B-Instruct，k̄=5.7，证据有出处。④「有限样本 coverage / false-stop」：正文定理 + 附录，经验 worst under-coverage −0.2 pp（第 10 页）。

**核验限定**（原样合入核验报告）：

## 7. 你可以怎么落地

**今天就能试**：仓库已 MIT 公开。先 `pip install trl-cgrpo` 或克隆 https://github.com/AryaFayyazi/CGRPO ，在 GSM8K 子集上用默认 K 网格跑通校准→自适应采样的日志，确认 k̄ 随训练下降。验收：同设置固定 G=32 对照，训练 rollout 计数明显更低，且验证 pass@1 落差不超过你样本规模下的二项噪声。

**要有数据或机器再试**：有一张 H100 级卡和完整六基准时，按论文 LoRA r=16、300 步复现 Table 1；再换 Llama/Gemma 看迁移。验收：报告 k̄_train 与 Savings 时单独列出校准 GPU 小时（对齐 Table 10）。

**暂时别碰**：没有可靠 verifier 的开放生成、纯偏好 RL，或校准集与线上分布严重错位时，共形阈值会失效；也不要在尚未理解 auto-δ 的情况下把 δ 拧到极端，早期可能全面禁用自适应。

## 8. 和你已有知识的挂钩

它像考试里的「自适应测验」：答得稳就少出题，不稳就加题；共形阈值相当于「我有多大把握可以收卷」。和启发式按奖励方差停采相比，最大区别是停采规则绑在有限样本 coverage 上，并且随策略变强周期重校准，形成自步调课程。

## 9. 存疑与代价

**局限**：作者写明需要 verifier、需要 exchangeability；主结果多为 LoRA、4–8B、300 步；部署环与定理假设不完全一致。**复现条件**：代码 MIT 已公开；论文 CC BY 4.0；权重未单列。**成本**：训练 rollout 下降，但周期性校准要额外采样；文内给出净加速约 3× 量级（特定设定）。**出处**：预印本，NeurIPS 2026 为自述。

**论文没回答、但决定你要不要动手的 3 个问题**：过程奖励或非二元奖励如何定义非一致性分数？多机数据并行下两阶段扩采的吞吐怎么保？校准集要多大才在你的任务分布上够稳？
