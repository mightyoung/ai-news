# 平均奖励 Q-learning 在「弱连通」MDP 里的收敛性 深度解析

- 论文：*On Convergence of Average-Reward Q-Learning in Weakly Communicating Markov Decision Processes*
- 作者：Yi Wan*、Huizhen Yu*（共同一作）、Richard S. Sutton（阿尔伯塔大学；Yi Wan 写作期间同时在 Meta AI；Sutton 另属 Amii）
- 出处：**arXiv 预印本**，https://arxiv.org/abs/2408.16262（v1，2024-08-29，cs.LG；正文 53 页）。论文页脚写明许可 CC-BY 4.0。我没有查到它被某个期刊/会议接收（用 WebSearch 检索，结果只有 arXiv 与 Amii 页面）；Yi Wan 的博士论文参考文献里把一个早期版本（arXiv 2209.15141）标为「To Be Submitted」（该信息来自检索结果摘录，我没有打开博士论文全文核对）。
- 阅读依据：**已读摘要、引言、背景（§2）、主结果与假设（§3）、实验（§3.3）、选项（options）部分的陈述、结论（§8）；§5–§7 的证明细节没有逐行验证**，只核对了定理陈述与证明思路的位置。

## 1. 一句话

给「持续运行、不分回合、目标是长期平均每步奖励最大」的强化学习（平均奖励准则）里一类 Q-learning 算法（RVI Q-learning，包括 Differential Q-learning），证明了它们在一个更宽的一类环境（弱连通 MDP）里**几乎必然收敛**，并刻画了收敛到的集合长什么样；同时把同样的结论推广到两个分层（options）算法。对工程的用处：这是**理论保证**，告诉你在什么条件下「平均奖励版 Q-learning」可以放心用在表格问题上；它不是新算法，也没有新的性能数字。

## 2. 解决的实际痛点

- 很多真实系统没有「回合结束」：服务器调度、网络路由、库存、航空收益管理、推荐等。论文引言列的应用有：航空收益管理、移动健康干预、推荐系统、网络服务委托。这类问题更自然的目标是**长期平均奖励**（reward rate），而不是带折扣的总和。
- 常见做法是用折扣 γ 很接近 1 的折扣 RL 去近似，会有数值不稳定（论文引言明确写了这点）；actor-critic 虽然实用，但通常要环境是遍历的（ergodic）。
- RVI Q-learning 是平均奖励下的 Q-learning 类算法，每步开销和折扣版 Q-learning 几乎一样（唯一的区别是：每步奖励要减去一个对「最优奖励率」的估计）。但之前的收敛证明（Abounadi、Bertsekas、Borkar，2001）只覆盖「单链（unichain）」MDP——也就是任何策略下长期都只有一个循环类。现实里很多问题里某些策略会把系统「困」在不同的循环类里，这就超出了单链假设，需要「弱连通」。

## 3. 方案思路（这是一篇理论论文，思路就是「证明什么」）

先把几个词讲明白：

- **平均奖励准则**：最大化 lim (1/n)·Σ r_t，即长期平均每步奖励 r*。
- **弱连通 MDP**：去掉那些最终不再会遇到的瞬态状态后，每个状态都能从任一状态到达（在某个策略下）。它允许存在「某个策略会把你困在不同小圈子里」的情形，所以比「单链」宽。
- **RVI Q-learning 的更新**（论文公式 3.1）：对被选中的 (s,a)，
  Q(s,a) ← Q(s,a) + α · [ R − f(Q) + max_{a'} Q(s',a') − Q(s,a) ]，
  其中 f(Q) 是对最优奖励率的估计，f 是 Q 的某个满足条件的函数（例如取某一个固定 (s,a) 的 Q 值，或所有 Q 之和的缩放）。
- **Differential Q-learning**：一个具体成员，维护一个单独的奖励率估计 R̄，TD 误差 δ = R − R̄ + max Q(s',·) − Q(s,a)，用 δ 同时更新 Q 与 R̄（R̄ += η·α·δ，论文公式 3.3–3.5）。

**主要结果**：

1. **解集合的结构**（Theorem 3.1）：算法的目标集合 Q∞（满足平均奖励最优性方程、且 f(q)=r* 的 Q）是非空、紧致、连通、可能非凸的；它比最优性方程的完整解集恰好少一个自由度（Theorem 7.1）。
2. **收敛**（Theorem 3.2）：在假设下几乎必然成立：(i) Q_n 收敛到 Q∞ 里一个**依赖样本路径**的紧致连通子集，且 f(Q_n)→r*；(ii) 当 n 足够大时，对 Q_n 取贪心得到的策略都是最优策略。
3. **特例**：在单链 MDP 中 Q∞ 退化为一个点，回到以前的结果。
4. **离策略与瞬态**（Corollary 3.1）：行为策略可以是任意（如固定的 80%/20% 随机）策略，只要覆盖条件满足。
5. **分层（options）**：对 Wan 等人 2021 提出的两个平均奖励 options 算法（一个「选项间」inter-option、一个「选项内」intra-option），在底层半马尔可夫决策过程（SMDP）弱连通的假设下证明了几乎必然收敛；论文称之前对这两个算法的收敛证明要求单链，且稳定性分析里有漏洞（Remark 6.1）。

**证明方法**（§6）：把算法当作异步随机逼近，用常微分方程（ODE）的方法；稳定性用 Borkar–Meyn（2000）的方法，并把它的噪声条件放宽（细节放在另一篇文章 Yu et al. 2023）；因为 ODE 有多个平衡点，所以需要利用弱连通 MDP 的解结构，把 Abounadi 等人的论证推广。

## 4. 怎么看「实验」、怎么识别夸大

这篇**几乎没有实验**，只有 §3.3 的「经验验证」：

- 两个**玩具 MDP**：一个 2 状态的连通 MDP；另一个在它基础上加一个状态 0，构成弱连通 MDP（状态 0 以 0.9 概率停留，奖励恒为 −5）。
- 两个算法：Differential Q-learning 与「f 取某一固定 (s,a) 的 Q 值」的 RVI Q-learning。
- 行为策略固定（选 solid 概率 0.8，dashed 0.2），步长 α_n = 1/n，每个算法在每个 MDP 里跑 **10 次，每次 20,000 步**；图里画每 10 步记录的较高 Q 估计，最终点都落在预期集合内。

怎么读：

1. 这只是**验证定理陈述**（Q 收敛到集合而非唯一点），不是性能比较，没有基线、没有基准环境。别把它当作「算法在真实任务上表现好」的证据。
2. 定理的前提不弱：**有限状态与动作（表格）**、**每个 (s,a) 以正的比例被无限次更新**（假设 3.3(i)：访问次数/n 的下极限大于零）、**步长要满足一堆条件并以每个 (s,a) 自己的访问次数为「本地时钟」**。用神经网络近似时这些保证不再成立——论文自己明确写了：引入函数近似「可能破坏收敛保证」，且不在本文范围内（引言）。
3. **收敛的是一个集合，不是一个点**：同一次运行里 Q 值可能在这个集合内持续漂移，论文用「sample path-dependent compact connected subset」描述；不过贪心策略最终是最优的（Theorem 3.2(ii)）。工程上，Q 的数值本身不能直接当「唯一真值」。
4. **不是收敛速率**：论文没有给样本复杂度或收敛速度（论文未说明；这是渐近结果）。
5. 论文承认的局限（§8）：步长依赖访问计数；RVI Q-learning 只处理「平均奖励最优性方程能刻画最优策略」的 MDP，不处理一般（多链）MDP；函数近似版本的收敛留作未来。
6. 资助：研究得到 DeepMind 与 Amii 支持（致谢部分）。

## 5. 落地步骤

**今天就能试**

- 如果你的问题是**表格规模的持续型任务**（状态动作不多、不分回合），可以实现 Differential Q-learning：每步 δ = R − R̄ + max_{a'} Q(s',a') − Q(s,a)；Q(s,a) += α·δ；R̄ += η·α·δ（η>0，论文公式 3.3–3.5），并与「折扣 Q-learning（γ=0.99/0.999）」对比，看哪个更稳。
- 做测试时检查：每个 (s,a) 是否被持续访问（用 ε-贪心或固定随机行为策略保证覆盖）；步长是否按各自访问次数衰减。
- 把上面论文里的 2 状态与 3 状态小环境搭一遍，当作单元测试：10 次运行最终 Q 值是否落进同一个集合。

**需要资源**

- 要上函数近似（神经网络）：论文不提供保证；论文 §8 提到可以参照 Wan 等人 2021b 附录 E 的写法扩展到函数近似，但把它的收敛性留作未来工作（我没有读 2021b）。
- 要证明/复核你自己的环境是否弱连通：需要分析转移结构；对大规模系统可能很难（我的判断）。

**可以跳过**

- 只是想训练 Atari、机器人一类带回合的任务：折扣设置已经足够，不需要平均奖励。
- 想要有收敛速率/样本复杂度保证的算法：本文不提供，应该看模型基（model-based）或有速率分析的平均奖励方法（论文引言提到了 Bartlett & Tewari 2009、Ouyang 2017 等，我没读它们）。

## 6. 和已知概念挂钩

- **Q-learning（折扣）**：几乎相同的更新结构，只多了「减去 f(Q)」这一项；
- **R-learning**：Sutton–Barto 第一版第 6.7 节的平均奖励离策略 TD 控制方法，教材原文在那一节写「There has been little experience with this method and it should be considered experimental」（见本列表第 4 篇）。本文研究的 RVI Q-learning/Differential Q-learning 是这条线的有理论保证的后续；两者的关系是我的判断（我只核对了教材 6.7 节与本文引言的描述，没有逐一比较算法细节）。
- **相对价值迭代（RVI）**：经典 MDP 算法（White 1963、Schweitzer 1971），RVI Q-learning 是它的无模型、异步、随机版本（论文引言）。
- **随机逼近 + ODE 法**：用 ODE 分析随机迭代，是理论 RL 常用工具（Borkar–Meyn）。
- **options / 分层 RL**：Sutton、Precup、Singh 的选项框架；本文给两个平均奖励选项算法补上了收敛证明。
- 与本列表其他篇：Frank Lewis 一组（第 8、9 篇）是控制论里做「连续时间、带稳定性」的 actor-critic；这里是离散时间、表格、统计意义上的收敛，两条线都在回答「在线学习什么条件下会收敛、能保证稳定」。

## 7. 疑点、局限与成本

- 尚未见同行评审出处（预印本）；定理很长，我没有逐行验证证明，结论以论文陈述为准。
- 收敛到一个**路径相关的集合**，不保证唯一的 Q。
- 不涉及速率、不涉及函数近似、不涉及一般 MDP。
- 实验只是玩具验证；「实用价值」要靠别人在真实问题上检验（论文未说明）。
- 成本：实现成本很低（改折扣 Q-learning 一行），难点在于判断你的环境是否满足假设，以及如何设计步长与访问覆盖。
