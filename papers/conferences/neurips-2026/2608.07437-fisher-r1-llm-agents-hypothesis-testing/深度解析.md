## 1. 一句话先懂它

让 AI 帮你做数据分析时，它代码能跑通，却常常选错统计方法，得出"显著"的假结论。作者做了一套 425 道真实数据题来测这件事，又用模拟数据加强化学习训练出一个 14B 小模型，在这套题上比几个大模型更稳。

## 2. 值不值得读：五个 C 速览

**类型**：新基准 + 新方法（训练出的开源模型）。**上下文**：接着数据分析 Agent 基准（DABstep、DA-Code 等）和"可验证奖励的强化学习"（DeepSeek-R1、DAPO）两条线。**关键假设**：一道题有一个"标准答案方法"，它算出的 p 值就是金标准；用模拟数据训练出的能力能迁移到真实数据。前者对统计题并不总成立（同一问题常有多个合理方法），作者自己也承认。**贡献**：①P-Bench：425 道开放式假设检验题，答案来自可复现的参考分析；②Fisher-R1：先监督微调再强化学习的 7B/14B 统计 Agent；③显示"只看结论对不对"会高估 Agent 的可靠性。**清晰度**：好，奖励和评分公式写得清楚，例题完整。**建议**：看到第 5 节；如果你在做数据分析 Agent 或 RL 训练，值得读原文第 4 节的奖励设计。

## 3. 它在解决什么麻烦

现在让 Claude、GPT 写代码分析一个 CSV 已经很平常：读数据、跑检验、给 p 值（在"其实没差别"的前提下，看到当前这么极端结果的概率；通常小于 0.05 就说"显著"）、写结论。问题在于：代码能跑、数字很漂亮，不代表方法选对了。

论文第 2 页 Fig. 1 举了个例子：检验"肿瘤突变负荷和肿瘤纯度有没有关系"，数据里有几个极端离群点。GPT-5.4 看到了离群点，却还是用了线性回归，得到 p < 2.2e-16，宣布"显著相关"；而对离群点不敏感的 Spearman 秩相关得到 p = 0.085，不显著。前者就是一次"假发现"。

你在工作中也会撞上：用 AI 分析 A/B 实验，延迟数据严重右偏，它默认上 t 检验；用户在多个时间点重复出现，它当成独立样本算；结果报告里写着"显著提升"，其实站不住。已有的数据分析基准大多只看"代码能不能跑、最后的数对不对"，不检查 p 值在这份数据的前提下是否有效。

如果这个问题被解决，意味着可以放心把一部分统计分析交给本地小模型（适合不能外发的医疗、业务数据），并且有一把尺子来衡量 Agent 是否"统计上靠谱"。

## 4. 他们怎么做的

**核心思路**：统计方法选得对不对很难直接打分，但可以间接打分——如果方法选对了，算出的 p 值应该和专家参考分析的 p 值接近。于是只要有"数据 + 参考 p 值"，就能给强化学习提供可自动核对的奖励。

**基准 P-Bench（第 4–6 页）**：题目来自三处——顶刊经济学论文（数据在 Harvard Dataverse）、生物学论文（数据在 cBioPortal）、范德堡大学生物统计教学材料。流程是：在干净环境复现参考分析并记录日志 → 复现不了的丢掉 → 生成"分析请求 + CSV + 隐藏答案"的题目包，再由受过统计训练的人审核。共 425 题，分 Easy 203 题、Hard 222 题；Hard 指需要仔细设定模型的方法（Cox 回归、工具变量、Tobit 等）或被故意加了离群点等数据陷阱。覆盖 17 类方法，没有一类超过 19%。Agent 在 R 语言沙箱里多轮写代码、看输出，最后交出方法、p 值和"拒绝/不拒绝原假设"。

**训练数据（第 6–7 页）**：用 LLM 为 27 种统计方法写模拟脚本，按"方法 × 场景 × 样本量 × 效应大小 × 提示风格 × 种子"组合生成 8,642 道题；答案是标准方法在模拟数据上跑出的 p 值。

**两阶段训练**：
- 监督微调（SFT，用老师示范的完整解题过程教模型模仿）：让 Claude-Sonnet-4.6 按"基础探索 → 细致探索 → 检查假设 → 选方法 → 结论"五步做 4,611 条示范，过滤后保留 3,851 条（第 7–8 页）。
- 强化学习用 DAPO（一种 GRPO 的改进版：同一题采样 8 条答案，比组内平均好的就鼓励，差的就抑制，不需要单独的价值网络）。奖励 = 0.9 × p 值接近度 + 0.1 × 结论对错，格式不合法直接 0 分。p 值接近度是先把 p 值换算成 z 分数（把概率换成"离中心几个标准差"），再按差距指数衰减——这样 0.5 和 0.6 的差别很小，而 0.1 和 1e-10 的差别很大（第 8–9 页）。

**如果让你复现**：

```
tasks = 模拟器生成(方法, 场景, 样本量, 效应, 提示, 种子)   # 答案=标准方法的 p 值
sft_data = 过滤(Claude 示范轨迹, 结论一致且 p 值同一数量级)
model = SFT(Qwen2.5-Coder-14B, sft_data, 3 epoch)
for 每批题目:
    rollouts = model 在 R 沙箱里多轮作答 × 8
    reward = 0.9*exp(-|z(p̂)-z(p*)|) + 0.1*(结论一致)
    DAPO 更新(组内相对优势, 裁剪 0.2/0.28)
```

论文未说明：P-Bench 里"受控扰动"的具体比例和种类分布；专家审核的人数和一致性。

## 5. 证据怎么看、别被什么忽悠

**表一：Table 1（第 10 页），主结果。** 想证明 Fisher-R1 比各路大模型更会做假设检验。测法：每题跑 3 次；Raw 只看"拒绝/不拒绝"对不对，Strict 还要求 p 值换算成 z 分数后与答案相差小于 0.5；pass@1 是三次的平均成功率，pass@3 是三次里任一次成功。结果（Strict pass@1）：Fisher-R1-14B 在 Easy 上 64.2、Hard 上 33.0；DeepSeek-V4-Pro 分别是 54.2 和 26.3；GPT-5.4 是 64.7 和 30.5；底座 Qwen-2.5-Coder-14B 是 41.4 和 23.7。说明：对底座的提升很明显；对 DeepSeek-V4-Pro 相对提升约 18.5% 和 25.5%，这就是摘要"平均 21%、最高 26%"的来源。对 GPT-5.4 是互有胜负：4 个 Strict 指标里赢 3 个，Easy pass@1 略输（64.2 vs 64.7）。另外在 Raw 指标上 GPT-5.4 仍然领先（例如 Easy pass@1 92.9 vs 87.4）。

**表二：Table 2（第 11 页），消融。** 想证明 SFT 和 RL 都必要。测法：7B 底座分别只做 DAPO、只做 SFT、两者都做。结果：Hard Strict pass@1 从底座 13.2 → 只做 DAPO 25.2 → 只做 SFT 14.3 → 两者都做 30.6。说明：单独 SFT 几乎没用，RL 是主要来源，SFT 作为热启动再加成。

**图三：Fig. 5（第 11 页），防记忆检查。** 用文本向量算题目相似度，P-Bench 题目和训练题的相似度明显低于训练题彼此之间，说明不是背题。

**水分检查**：
- **自建评测**：P-Bench 是作者自己建的，Fisher-R1 的训练目标（p 值接近参考答案）和评测指标（Strict）高度一致，天然有利于它；别人的模型没针对这个指标优化。
- **"唯一正确方法"假设**：Strict 把参考分析的 p 值当金标准，但作者也承认同一问题常有多个合理方法（第 9 页）。Fisher-R1 学到的可能部分是"猜参考答案用的方法"。
- **误差**：每题 3 次采样、报了标准差，这一点做得好；但 GPT-5.4 的 Easy Strict pass@1 标准差是 ±3.3，与 Fisher-R1 的 0.5 分差距在噪声内。
- **算力不对等是反向的**：14B 对比百亿级大模型，小模型赢说明定向训练有效，这点可信。
- **换场景**：只测 R 语言、单个检验；多重比较、Python 生态都没测。

## 6. 可信度与核验限定

**主张对照**：
- "P-Bench 有 425 道题"——第 1、6 页，**够**。
- "单次成功率相对 DeepSeek-V4-Pro 平均提升 21%，最难任务最高 26%"——Table 1，**够**，但必须说明是 Strict pass@1。
- "超过 GPT-5.4"——**部分够**，只在 4 个 Strict 指标中的 3 个；Raw 指标上 GPT-5.4 更高。

**核验限定（原样合入 2026-11-02 核验报告）**：
- P-Bench：425 道开放式假设检验题，覆盖经济学/生物学/医学，作者自建并专家核验（p1、p6）
- 摘要 21%/26%：对应 Table 1 Strict pass@1 相对 DeepSeek-V4-Pro——Easy 64.2 vs 54.2（≈+18.5%）、Hard 33.0 vs 26.3（≈+25.5%），平均约 22%；Strict 要求结论正确且 |∆z|<0.5；每任务 3 次 rollout（p9–p10）
- 相对 GPT-5.4：Fisher-R1-14B 在 4 个 Strict 指标中 3 个更高，P-Easy Strict pass@1 略低（64.2 vs 64.7）（p10）
- PDF 第一单位为 Stanford Biomedical Data Science；NeurIPS virtual 前三位列为 UW–Madison；GitHub 无 LICENSE，HF 权重 apache-2.0，P-Bench CC BY 4.0

**打折提醒**：对外引用别说"14B 打败 GPT-5.4"，应说"在作者自建的 P-Bench 上，4 个严格指标中 3 个超过 GPT-5.4"；21%/26% 要带上"Strict pass@1、相对 DeepSeek-V4-Pro"。

## 7. 你可以怎么落地

**今天就能试**：把论文 Teacher 用的五步流程（基础探索 → 细致探索 → 针对候选方法检查假设 → 选方法并分析 → 结论）写进你让 AI 做数据分析时的系统提示词，并要求它在给 p 值前明确写出"检查了哪些前提、结果如何"。挑 10 个你过去做过、知道正确结论的分析（例如右偏的延迟数据、有重复用户的 A/B 实验），对比加提示前后的方法选择。验收：方法选择合理的比例上升，且每个结论都能指出它检查过的前提。

**要有数据或机器再试**：从 Hugging Face 下载 P-Bench 和 Fisher-R1-14B，在本地 R 环境里跑一遍 Easy 子集（14B 推理一张 48GB 或两张 24GB 显卡可以跑，速度看实现），与你常用的模型对比 Raw 和 Strict 两个指标。如果想自己训练同类 Agent，论文报告 14B 的 RL 在一台 H200 节点上约 36 小时（第 23 页），还要搭 R 沙箱和模拟题生成器。注意代码仓库目前没有许可文件，用于公司内部前先确认授权。

**暂时别碰**：别让任何 Agent（包括 Fisher-R1）的统计结论直接进入决策或报告而无人复核。作者自己也说这是"评估和监督工具，不是替代人工统计审查"（第 12 页）。它只测单个检验，多重比较、复杂因果设计都没覆盖。

## 8. 和你已有知识的挂钩

奖励设计很像单元测试里的"对拍"：你不知道中间怎么写才对，但有一份参考实现的输出，拿结果去比。把 p 值换成 z 分数再比较，类似监控里对延迟取对数再看差距，避免极小值附近的差别被淹没。和普通数据分析 Agent 最大的区别是：它奖励的是"数字和参考分析对得上"，而不只是"代码能跑"或"结论方向对"。

## 9. 存疑与代价

**局限**：作者承认只评估单个检验、未覆盖多重比较（第 12 页）。我读出来的还有：训练目标与评测指标同源；"标准方法唯一"的前提对很多真实问题不成立；只支持 R。

**复现条件**：代码、权重、数据都已公开；但代码仓库根目录无 LICENSE 文件，严格讲默认不授权再使用；权重 apache-2.0、数据 CC BY 4.0 可以放心用。

**成本**：SFT 示范数据来自 Claude-Sonnet-4.6（要 API 费用）；14B RL 约 36 小时 H200 节点；推理时 Agent 要多轮执行 R 代码。

**出处**：NeurIPS 2026 Oral，同行评审过；单位在 PDF 和 NeurIPS 网站上不一致（Stanford vs UW–Madison），属于填报差异，不是造假信号。

**论文没回答、但决定你要不要动手的三个问题**：
1. 换成 Python（statsmodels/scipy）环境，训练出的能力还在吗？
2. 当一个问题有两三种都合理的方法时，Fisher-R1 会说明不确定性，还是只挑一个？
3. 在你自己的业务数据（不是论文数据）上，它比"好提示词 + 大模型"强多少？
