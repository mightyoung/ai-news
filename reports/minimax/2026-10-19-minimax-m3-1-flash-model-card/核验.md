**4. 风险点**

- 我方归档写“仓库未放权重”，与 HF API 实测（48 个分片约 250 GB）不符，需要修正。
- 官方说的速度（P50 170+ TPS）与 Artificial Analysis 实测中位数 119 tok/s 有差距。
- BankerToolBench 用厂商自家模型当评委。

**5. 建议下一步**

- README 摘要末句「截至 10-30 仓库未放权重」改为：「权重已在 HF 公开（MiniMax Community License：非商业免费，商用需署名并通知，年收入超过 2000 万美元的需授权）；API 价格每百万 token 输入 $0.15 / 输出 $0.60；第三方 AA 智能指数 29。」
