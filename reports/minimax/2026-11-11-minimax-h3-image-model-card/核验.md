- 页码均为 PDF 物理页；证据在盒子本地 `evidence/2026-11-11/`，不进仓库

**1. 结论一句话**

⚠️ 部分核实（存疑）：HF 模型卡与权重存在；DiT 33.1B 参数、50 层（hidden 5376、56 头、FFN 14336）与 `transformer/config.json` 一致，transformer 分片合计 66.28 GB，按 BF16 折算约 33.1B 参数，也对得上。但卡内有两处与仓库不一致：「BF16 (DiT) 68.65 GB」与同卡下载表的 transformer/ 66.28 GB 不符；卡上写文本编码器「不在本仓库」，HF API 却显示仓库里有 14 个 text_encoder 分片（约 66.7 GB）。许可是自定义社区许可，排除欧盟、英国、韩国、美国。

**4. 风险点**

1）「BF16 (DiT) 68.65 GB」与同卡下载表及 HF API 的 transformer/ 66.28 GB 不符；2）卡写文本编码器不在本仓库，但仓库实有 text_encoder/ 14 个分片（约 66.7 GB）；3）README 留有 TODO 注释和空链接。

**5. 建议下一步**

- README 摘要中「BF16 DiT 约 68.65 GB」改为：「模型卡 Model Zoo 写 BF16 (DiT) 68.65 GB，但同卡下载表和 HF API 的 transformer/ 为 66.28 GB，68.65 GB 约为 DiT + VAE + tokenizer 合计」。
- 补一句：「卡上写文本编码器不在本仓库（由 MiniMax-H3 加载），HF API 显示仓库实有 text_encoder/ 约 66.7 GB，全仓约 204 GB。」
- 许可一句补：「适用地域不含欧盟、英国、韩国、美国；年化收入超 100 万美元或提供托管服务需另行授权。」
