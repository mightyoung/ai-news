## 摘要

博客称 Google DeepMind 研究人员用 AlphaProof Code 引导 AI 智能体，对 Signal 协议底层真实代码的关键安全属性做出数学证明；由 Gemini Carbon 驱动的智能体生成超过六百万行 Lean，审计后只有约 1% 的代码库需要人工复看（只见于博客，论文未给该比例）；整个验证用时四周（论文为 5 人团队并行，第 25 页）；并把两个已修复的真实 bug 重新引入隔离版本，系统在两种情况下都给出了该版本不安全的机器检查证明（均为厂商自报）。博客链接了技术论文，已另建文件夹。
