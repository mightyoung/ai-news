## 摘要

OpenAI 发布 LifeVal，一个衡量模型帮人完成日常事务（照护、健康、教育、家务管理、个人财务、购物、办理政务）的评测。任务来源是美国时间使用调查（ATUS）、多国时间使用研究（MTUS），加上一份 3,995 人的人口代表性新调查。页面列了几项示例任务的分数（如 93.1%、100%），但没写指标定义和对应模型；文中说过去一年用这套评测跟踪并推动模型在浏览器使用、电脑使用和连接器任务上的改进。
