## 摘要

LongCat-2.5 是原生多模态、面向长程 Agent 任务的 MoE 模型，在 LongCat-2.0 基础上加强视觉理解和 Agent 编程。博客写了不少训练细节：视觉信号用多级离散 token（对原生分辨率特征做残差向量量化 RVQ），大规模异步长程 RL（部分 rollout、过滤零梯度组、裁剪新旧策略概率差），以及多教师在线蒸馏（MOPD，全词表 KL）；训练和推理在国产 AI 加速卡上做，W4A4 推理相对 W8A8 基线预填充吞吐 +43.3%、解码吞吐 +42.77%（厂商自报）。评测表里对比模型带 * 的取自公开报告，其余为自跑，仅供参考。
