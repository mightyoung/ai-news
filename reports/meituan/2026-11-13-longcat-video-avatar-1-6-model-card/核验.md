## 4. 风险点

有证据的不一致（需在 README 写清，不因此改判无法核实）：

1. **HF 模型仓声明 MIT 并链接 `LICENSE`，但该文件 404**（`LICENSE` / `license` 均为 EntryNotFound；siblings 无许可文件）。完整 MIT 原文在 GitHub 仓 `LICENSE`（Copyright (c) 2025 Meituan）。cardData 与 GitHub API 均标 mit。
2. **报告与卡片对已发布 LoRA 的命名不一致**：报告为 GRPO + OPSD；卡片 / GitHub README 为 DMD + OPSD（`loraA` / `loraB`）。原文未说明对应关系。
3. **捆绑 `whisper-large-v3/` 自述 Apache-2.0**，卡片 MIT 段未覆盖说明；该子目录也没有 LICENSE 文件。

限定（不算矛盾）：评测数字为厂商自报；参数量与 API 价格官方未披露；Usage Considerations 使用了 LLM 模板措辞；项目页演示素材有学术使用声明。
