## 4. 风险点

有一条**跨文档、有证据的不一致**（不是报告内部数字互相打架）：

- 技术报告写后训练两路 LoRA，推理时把 **GRPO LoRA 与 OPSD LoRA** 一并接入冻结基座（物理第 3–4、6、8 页，Fig. 3）。Hugging Face 模型卡与 GitHub README 则写 1.6 检查点包含两条 LoRA：`loraA/lora.safetensors` 为 **DMD LoRA**，`loraB/lora.safetensors` 为 **OPSD LoRA**；示例命令使用 `--lora_path loraB/lora.safetensors` 与 `--use_distill` / `--mix_steps`。HF siblings 中确有这两个文件，**没有名为 GRPO 的适配器文件**。原文未解释 GRPO 适配器如何对应到已发布文件，此处不猜测（例如不推断其已并入 `base_model`）。

其余未见页面与 PDF 不符、或 Arena / Fig. 8 数字前后对不上。下列为**限定**，不算矛盾：评测均为厂商自报；Fig. 2 选帧最高 09:56；HF 仓无独立 LICENSE 文件；参数量与价格官方未披露；摘要对商业模型「outperforms」的措辞需以第 2 名结果为准。
