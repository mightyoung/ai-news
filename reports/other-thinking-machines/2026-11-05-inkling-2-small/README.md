## 摘要

发布第二代 Inkling 小杯模型。厂商自报：Artificial Analysis Intelligence Index 31（博客自报；2026-11-06 AA 榜单第三方核对一致）；预训练 H1 约 8.4T tokens（GB300 NVL72、原生 NVFP4），随后 H2 3.8T（512K）、H3/H4 部署格式与 agent 轨迹；主 RL 运行 1,075 步、逾 1700 万 rollouts、9 天、2,048 GPU、逾 4×10²³ FLOPs。当前经 Tinker 提供，计划完成外部安全测试后以 Apache 2.0 开源权重。**暂无独立 PDF 技术报告**（细节在博客中）。
