## 摘要

NVIDIA 在 Hugging Face 博客发布 Cosmos 3 家族的四个开放权重检查点，用于交互式世界模拟和多传感器多视角驾驶场景生成。博客写四个模型都是 Cosmos 3 Nano 的后训练版本、可训练参数 16B（厂商自报），许可为 OpenMDW1.1。博客概述了四阶段训练配方（双向适配、Teacher Forcing、一致性蒸馏、Self Forcing），完整细节见同日技术报告。
