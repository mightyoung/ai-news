## 3. Robert Lange（@RobertTLange）· 2026-10-23 03:30 CST

> What if optimizers could reason adaptively?
>
> OPAL (OPtimizer with an Agent in the Loop) by @SimulatedAnneal et al. puts an LLM agent inside the training loop. It's not an outer-loop hyperparameter tuner. It watches the training dynamics and rewrites the optimizer's source code during training.
>
> The interface is two files, both written by the agent:
>
> 1. analysis: probes the agent writes itself to pull out whatever stats it wants (per-group grad norms, update/weight ratios, cosine similarity between consecutive gradients, spike detectors). Raw weights would flood its context, so it decides what to look at.
>
> 2. updater: the update rule, run on every step. Since the interface is code, anything can change: LR schedules per param group (including raising the LR mid-run), AdamW→Muon on specific tensors, bf16 vs fp32 per tensor, momentum resets, clipping, gating bad batches, even A/B tests on itself.
>
> analysis → reasoning → update rule → training → analysis. The algorithm is no longer a fixed object. Part of it is an agent. It's fully zero-shot: no meta-training runs.
>
> This native embedding of agents within established algorithms is super interesting: it enables online meta-learning, with the meta-learner swapped out. It reminds me a lot of @Luke_Metz 's work on learned optimizers. VeLO amortized optimizer learning into network weights through huge meta-training across thousands of tasks. OPAL gets its "meta-knowledge" for free from LLM pretraining (papers, folklore, debugging intuition) and adapts within a single run, through reasoning in context instead of gradients. That partly avoids the problems of meta-optimization: truncated unrolls, short-horizon bias, generalizing to unseen tasks.
>
> The interactive blog post is great with many takeaways re agent implemented strategies: per-tensor adaptive clipping, extend SWA, momentum adaptation based on inferred flatness.
>
> Blog: https://xingjianbai.com/reactive-optimizers/
> Code: https://github.com/xingjian-bai/opal
