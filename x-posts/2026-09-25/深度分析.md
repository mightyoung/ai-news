## 1.（重点）D. Gemini 3.8 Flash TTS / Flash-Lite TTS：可定制语音工作室进 API

**标题**：Create and deploy custom audio — Gemini 3.8 Flash TTS（定制口音/特征）与 Flash-Lite TTS（效率与规模）  
**链接**：  
- X（@GoogleDeepMind）：https://x.com/GoogleDeepMind/status/2102781530867126505  
- 官方博客：https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-text-to-speech/  
- API 语音生成：https://ai.google.dev/gemini-api/docs/speech-generation  
- Voice design：https://ai.google.dev/gemini-api/docs/voice-design  
- 模型卡：`gemini-3.8-flash-tts` / `gemini-3.8-flash-lite-tts`  
- 定价：https://ai.google.dev/gemini-api/docs/pricing  

**一句话结论**：Google 把 TTS 从「选预设音色念稿」升级成「Voice design / 复制 → 持久 `voice_...` ID → 结构化 `speech_metadata` 导戏」的**可部署音频组件**；与昨日 ChatGPT Voice「插件+Work 语音执行平面」正交——前者是 API 级合成引擎，后者是带副作用的助手运行时；工程上应按「内容产线 / 语音 agent 级联」选型 Flash vs Flash-Lite，并单独做同意、水印与区域可用性门控。

### 原文事实（可核对）

- **时间**：DeepMind 帖 `2026-09-23T15:25:59.000Z` ≈ **CST 2026-09-23 23:25**；官方博客标注 **Sep 23, 2026**；speech-generation / voice-design / pricing 页 `Last updated 2026-09-24 UTC`。  
- **X 帖 note 全文要点**：推出新 TTS——(1) **Gemini 3.8 Flash TTS**：用口音与特征设计独特音色；(2) **Gemini 3.8 Flash-Lite TTS**：为效率与规模打造，可选用自建风格或 expansive production-ready library。  
- **官方博客可核对能力（非自评榜分部分）**：  
  - Flash：自然语言提示从零设计角色声；逐行控制演技、节奏、方言切换、backchanneling；面向游戏、有声书、播客、互动媒体。  
  - Flash-Lite：高吞吐、成本效率；配音、音频内容、表达型 voice agent。  
  - **Voice design**：100+ 语言/方言自然语言定制；**2,000+** production-ready 音色（含墨西哥西语、魁北克法语、苏格兰英语等区域变体）。  
  - **Voice replication**：约 **30 秒**参考音频；须提供与参考说话人匹配的**口头同意录音**后才可创建；另提 SynthID 水印与 **C2PA** 凭证。  
  - 自定义音色可保存复用；**Voice remixing**（调音色/音高/语速/口音）标注 **Coming soon**。  
  - 长时生成宣称跨小时保持音色稳定；原生双说话人剧本；支持非言语 vocal burst 与 `|mhm|` 类 backchannel。  
  - **SynthID**：Gemini Audio 生成的每段音频均嵌入不可感知 SynthID，便于检测为 AI 语音。  
  - **可用性**：开发者——Gemini API + Google AI Studio（即日起）；企业——Gemini Enterprise API **Coming soon**；面向大众——Google Vids；Flash 进 Gemini Notebook、Flash-Lite 进 Vids（博客分列）。  
  - **区域限制（博客脚注）**：AI Studio 的 voice replication **不可用**于 Illinois、Texas、EEA、UK、Switzerland、India。  
- **API 文档可核对工程边界**：  
  - 模型码：`gemini-3.8-flash-tts` / `gemini-3.8-flash-lite-tts`；同一 API schema，改模型名即可切换。  
  - **TTS ≠ Live API**：TTS = 文本精确复诵 + 细粒度风格控制（播客/有声书）；Live = 交互式、非结构化双向音频。TTS **不支持** Live API / function calling / thinking 等（模型页 Capabilities）。  
  - 输入仅文本、输出仅音频；单请求多说话人最多 **2** 人（预置音色）；自定义 `voice_...` 多角色需**分说话人逐轮合成**再拼接。  
  - Token 限额（serving）：input **8,192** / output **16,384**。  
  - 语言：Flash **130**；Flash-Lite **101**（文档表）。  
  - 3.8 schema 迁移要点：正文 = 逐字稿；回合级情绪/节奏进 `speech_metadata.style`；瞬时非言语用尖括号 inline tags； unary 默认 **WAV**（非旧版默认 raw L16）；stream 默认 headerless L16 24 kHz mono。  
  - Voices API：`POST /v1beta/voices`，`type=prompted|replicated`；stateful `store=True` → `voice_...`，**每项目 200 条、TTL 1 年**；stateless replication `voicekey_...` TTL **7 天**。  
  - 生态：文档/博客点名 Agora、LiveKit、Pipecat、Vercel 等可接 API 部署。  
- **定价（官方 pricing 页，Paid Standard，至 2026-12-31；2027-01-01 起上调——勿与通用 `gemini-3.8-flash` 文本价混淆）**：

  |---|---|---|---|
  | `gemini-3.8-flash-tts` | $0.50 → **$1.00**（2027-01-01） | $9.00 → **$18.00** | ≈ **$0.00225** → $0.0045 |
  | `gemini-3.8-flash-lite-tts` | $0.50 → **$1.00** | $6.00 → **$12.00** | ≈ **$0.0015** → $0.003 |

  \*官方表给出的 equivalent per 10s；另有 Batch / Flex / Priority 档。旧版 `gemini-3.1-flash-tts-preview` Standard 仍为 $1 / $20，Flash-Lite 3.8 在公开价上明显更省。  
- **厂商自评榜（勿当独立复现）**：博客称 Flash 在 Hume AI Voice Design Benchmark **#1（71.4）**、accent modeling **60.8**；Flash / Flash-Lite 分列 Overall Quality Index **#1 / #2**；Voice Arena 多语种盲测「靠前」——仅作文宣信号。

### 机制拆解（产品架构｜对照 ChatGPT Voice）

1. **产品形态：音频工作室组件，不是助手运行时**  
   链路是：`Voices.create`（设计/复制）→ 持久 `voice_id` → `interactions.create`（`response_format=audio` + `speech_config`）→ WAV/PCM。无插件、无日历/邮件副作用、无 Work 文档态。这是**可嵌入产线的 TTS 微服务**。

2. **对照昨日 B：ChatGPT Voice 的「语音执行平面」**  

   | 维度 | Gemini 3.8 TTS（本帖） | ChatGPT Voice + 插件/Work（昨日 B） |
   |---|---|---|
   | 部署单元 | API / AI Studio 合成引擎 | ChatGPT 产品内语音通道 |
   | 输入/输出 | 文本 → 音频（精确复诵） | 语音意图 → 工具调用 / Work 产出 |
   | 副作用 | 无（除非你自己接下游） | 邮件、日历、Slack、建站等 |
   | 模型角色 | Flash（表现力）/ Flash-Lite（吞吐）双档 TTS | Astra / Sol / Luna 推理路由 |
   | 控制面 | `speech_metadata` + inline tags + voice ID | 确认门、插件白名单、任务状态机 |
   | 安全焦点 | 同意录音、SynthID、区域封禁复制 | 误听+误外发、账单升档 |

   **读法**：要「品牌声线 / 有声内容 / agent 嘴皮子」→ Gemini TTS；要「开口办事」→ Voice 执行平面。二者可组合（LLM/agent 出稿 → TTS 播报），但**不要把 TTS 当成带插件的 Voice 替代品**。

3. **人格 vs 演技两层分离**  
   永久特质（年龄、音色、口音）进 Voice design；回合情绪进短 `style`；瞬时笑声/停顿进 `<...>`。文档明确反对在 `style` 里改性别/年龄或塞长「Director's Notes」——那是旧预览模型漂移主因。

4. **双档经济学**  
   同 schema、不同保真/语种覆盖/价。Flash-Lite 官方定位为替代 `gemini-3.1-flash-tts-preview` 的生产主力；Flash 吃演播级与难方言。Batch/Flex 再砍价，适合离线配音队列。

5. **信任栈写进创建路径**  
   复制必须同意音频匹配；全量 SynthID；博客提 C2PA。区域直接关掉 Studio 复制——合规是产品开关，不是事后文案。

6. **激励**  
   对内打通 Notebook / Vids / 未来 Enterprise；对外用 API + 合作伙伴（配音、agent 平台）卖「无限音色库」与分钟级音频账单，与 Live 实时对话产品线形成互补而非替代。

### 工程落地清单（5–8 条）

1. **选型矩阵写死**：演播/多方言/重演技 → `gemini-3.8-flash-tts`；voice agent 级联、朗读、批量配音 → `gemini-3.8-flash-lite-tts`；同请求只改 `model` 做 A/B。  
2. **音色资产库**：用 Voices API 建 `prompted` 品牌声；存 `voice_...` + display_name；监控 **200/项目** 与 **1 年 TTL**；复制场景区分 stateful vs 7 天 `voicekey_...`。  
3. **剧本编译器**：上游 LLM 只出「逐字稿 + 结构化 metadata」；禁止把「开心地说：」写进会被念出的 `text`；统一 tip 括号 tags 与 `|backchannel|` 规范。  
4. **双说话人流水线**：预置音色可用 `speakers` 一次合成；自定义声线按说话人分请求，统一要 `audio/l16` 再拼接，避免 WAV 头重复。  
5. **流式播报**：agent 嘴皮子开 `stream=true`，按 24 kHz mono L16 播放；unary 存档走默认 WAV。  
6. **同意与合规门**：复制流程强制存同意音频哈希、说话人匹配结果、司法辖区检查（IL/TX/EEA/UK/CH/IN 等 Studio 禁区）；对外分发保留 SynthID 检测钩子。  
7. **成本与缓存**：按「文本 token + 音频秒数」建预算；长系列固定前缀试 Context caching；离线队列走 Batch/Flex；对照 pricing 页勿套用通用 Flash 文本价。  
8. **与 Voice 执行平面解耦**：若产品同时要「办事」和「好听」，拆成 Agent/Work 层 + TTS 层；TTS 层无写权限，避免把合成服务做成高权限入口。

### 风险

- **仿声滥用与同意绕过**：30 秒复制门槛低；区域禁用不等于 API 全局同策，需自建法务门控。  
- **SynthID 非银弹**：可检测 ≠ 全平台已接入检测；下游若转码/混音可能削弱可检性（公开材料未给抗性指标）。  
- **多说话人自定义限制**：一次请求双自定义声线需自拼，易引入节奏/电平不一致。  
- **漂移与超长内容**：官方宣称小时级稳定，仍需自建「同句重跑 + 嵌入相似度」回归；超限靠切章。  
- **价与能力错配**：Flash-Lite 语种少 29 种；省钱后发现目标方言不在 101 表内。  
- **厂商榜分**：Hume / Voice Arena 名次为自评引用，采购决策应以内部听感与 ASR 回读为准。
