【10/14 深挖 A】Anthropic 自研源码管理系统 Scion

先说结论：Anthropic 每天合并的代码变更，5 月约 2,500 个，9 月超过 30,000 个。他们用五个月把 monorepo 从 git 迁到了自研的 Scion，团队 7 人，同时还做了评审系统 Antique。

设计上和 git 有几处根本不同：
- 默认客户端始终在线，历史查询、合并、建 commit 都放在服务端做。
- 变更以 changeset 为单位写日志，blame 之类的派生数据按父 changeset 递归算出来。
- 工作区默认稀疏、按需加载，CI 很多时候直接调 API 查库，不落盘。
- 检出走三层：节点 daemon、区域缓存、权威服务器。
- 不再用全局 merge 锁，改成合并后、部署前做测试；评审重点看变更意图，敏感路径按风险分级把关。

效果是 Anthropic 自报的：基础设施占用约为原来的 1/200，CI checkout 快两个数量级，节省约 25% CPU。

对照 Chollet 的说法：agent 帮个人省 2 小时，如果团队要多花 3 小时对齐和评审，回报就是负的。

给中小团队的建议：先把已经定下的决策共享给所有人和 agent，评审按风险分级，CI 用稀疏检出，合并后再设质量关卡并能快速回滚。不必自研源控，继续用 git 加这些做法就行。
https://www.anthropic.com/engineering/redesigning-source-control

【10/14 深挖 C】XBOW 打出 Chrome 全链漏洞（只讲防守方关心的部分）

事件：XBOW 的研究员配合公开模型（帖子原文写的是 GPT-5.6 Sol），8/2 到 8/7 共 6 天，算力约 4 万美元，做出一条 Windows Chrome 全链漏洞，拿到 2026 年新规则下第一笔 25 万美元全链赏金。上面这些数字都是 XBOW 自报的。漏洞已经修复，请大家更新 Chrome 并重启浏览器。

分工：人定目标、做验收、负责把各环拼起来；agent 并行跑多个窄任务，包括搜源码、写 PoC、写各阶段草稿。每个阶段都留了备用路径，这样某一环和别人撞车时只换那一环就行。这次确实撞了一次。

成本：4 万美元只是 API 费用，资深研究员的时间和已有工具链都没算进去。

防守方可以借鉴的做法：在授权范围内用同样的思路测自己编译出来的软件；红队任务按组件边界拆开；补丁更新做到强制重启生效；单独记账，比较 agent 费用和专家工时。

对照：Anthropic OSS Scanner 和 CVP 的分析见 10/10 稿 B。CVP 之前的指针写在 10/6，实际在 10/10 B。

口径提醒：帖子里的 GPT-5.6 Sol，和我们之前稿子里的产品名 GPT-6.1 Sol 是不是同一个模型，还没核到官方对照。CVE 方面，通稿列了两个：CVE-2026-85045（WebP）和 CVE-2026-78952（Crashpad）。
https://xbow.com/blog/xbow-built-a-chrome-full-chain-exploit

【10/14 深挖 D】Gemini 4 Argon 全球上线，演示「视频→仿真→真机」

相对 10/1 的新增：
1. 全球可用。付费 API、AI Studio、Antigravity 都能用，Gemini app 按订阅档开放。
2. Fairwind 扩到数百家合作伙伴。
3. 新的机器人演示：Argon 看人类扔沙包的视频，标出空间坐标和全身关节动作，自己写 MuJoCo 仿真代码，再迁到 Apptronik Apollo 真机上，连中 7 次。

价格没变，入门价仍是 $2/$10，11/30 之后恢复 $4/$20，详见 10/1 §1。

口径：「连中 7 次」是官方自报，总共试了几次、人工介入多少都没公开。ERQA 87% 也是自报。

和其他路线对比：RoboJEPA 和 LeWAM（见 10/11 B）走的是潜空间世界模型加规划；Argon 公开的路径是让模型写代码搭仿真，物理计算交给仿真引擎。【推断】这两条路可以组合着用。

落地要点：
- 从开发者博文里的 Real2Sim 提示词模板起步。
- 准备仿真验收清单，包括接触对齐、能用种子复现。
- 上真机先低速，加力矩限制。
- 报告成功率时带上区间，不要只报最长连中。
https://developers.googleblog.com/en/gemini-4-argon-for-robotics/
